# 商衡SI · 前端体验全面审核与「温玉丹青」视觉灵魂升级研究

日期：2026-11-18  
性质：前端架构、体验审美深度诊断与下一代 UI 升级方案（配套交互式实时预览 Artifact）

---

## 一、深度诊断：为什么当前界面显得“色调单一、图标干瘪、缺点灵魂”？

V3.4 的“素纸版”（`docs/v34/design/visual.md`）成功治好了早期版本“刺眼蓝光泛滥、灰底贴粗糙白块”的毛病，但在执行**减法**时出现了明显的**矫枉过正（Over-correction）**。通读 `theme.css`、`skin.css`、`SiLogo.vue`、`MainLayout.vue` 与 `EntryStrip.vue` 后，可以精准定位抽干界面灵魂的**五大病灶**：

### 1. “去光效”变成了“去空间、去温润”——冷铅灰压死了纸面的呼吸感
* **问题根源**：`theme.css` 将画布 `--si-bg-canvas` 与面板 `--si-surface-1` 设为完全相同的 `#FBFBFA`，删除了一切器物投影，仅靠一道道 `#E6E6E2` 的 1px 直线分割；更矛盾的是，纸面偏暖，但五级墨色（`#1A1C20`、`#3A3D44`、`#646870`、`#8A8E96`、`#B9BCC2`）的蓝色通道全部高于红色通道，属于**工业冷铅灰（Cool Slate）**，夜幕底色 `#15171A` 也是毫无色相倾向的死灰黑。
* **视觉后果**：界面失去了“桌面（Canvas）→ 温润器物（Surface）→ 焦点纸页（Active Sheet）”的微弱明度差与触感微阴影，看起来不像温润厚实的东方棉宣，而像一张**扁平冰冷的工程线框图（Wireframe）**。

### 2. 色彩配额锁得过死，“全员涂黑”剥夺了正向情绪回馈與视觉锚点
* **问题根源**：
  * 侧栏选中、页签下划线、快捷标签选中、分段控件全部改为灰色底配黑字，主色“松针青”在日常浏览中几乎隐形；
  * **取消了代表安心与达成的正向色彩**：`--si-ok` 被改成了深墨灰 `#3A3D44`。用户核完几十处脱敏、审完百条标书要求，满屏只有刺眼的红（危险）、黄（警告）和沉闷的黑灰对勾，**只有“挑错的焦虑感”，没有“安全受控、合规就绪”的愉悦感与掌控感**；
  * **文件徽标全部去色**（`History.vue` 等把 PDF/DOC/XLS 全变成灰框黑字），扫视列表时丧失了瞬间辨识文件类型的直觉锚点。

### 3. 品牌标识（“松鳞”）与全站图标“有形无骨、均质单薄”
* **现行 Logo（`SiLogo.vue`）的问题**：外轮廓采用圆润松散的三次贝塞尔水滴/松果线，内部却硬塞直线菱形，曲直几何语言割裂；缩至侧栏 24px 时退化为一个暗沉的粗线水滴框，既未传达**「商（契约圭璋）」**与**「衡（法度准绳、精准权衡）」**的权威感，也缺乏高端政企软件应有的锋芒与记忆点。
* **功能图标与插画的问题**：
  * 全站一刀切使用 `@lucide/vue` 16px、`1.75px` 等粗单色细线，即使选中或悬停也毫无主色点染或双色调（Duotone）体积感；
  * 首页 `EntryStrip.vue` 四幅 `72×44` 入口图全是 `1.25px` 空心线框（火柴盒式简笔画），没有半透明色釉面（Glaze Fill）衬托，显得单薄干涩。

### 4. 字体排版缺乏“编辑级（Editorial）戏剧反差”
* 全站从大标题、欢迎语到正文、表头清一色使用无衬线黑体 `400 / 500 / 600` 相邻字重，缺少人文书卷气质的标题衬托；金额与关键指标虽用了等宽字体，但整数主干与小数尾数（`.00`）同等黑度并列，缺少顶级金融/法务终端的视觉主次精修。

### 5. 核心安全与专业动作缺少“仪式感微体验（Signature Craft）”
* 「商衡SI」最引以为傲的灵魂是**“本机离线锁住机密 → 云端只见代号 → 评标一锤定音”**。但在界面上，本机脱敏状态只是一行普通小字，原文/AI 视野切换只是硬切文本，核对确认缺乏细腻的微动效回馈，未能让使用者在操作瞬间产生“这件工具真考究、真安全”的享受感。

## 二、破局方案：「温玉丹青（Warm Jade & Burnished Amber）」设计体系

不走回“廉价霓虹发光风”的老路，而是在“克制、耐看、专业”的根基上，注入**东方商道法度的温润器物感**与**现代顶尖生产力工具（Linear / Harvey AI / Apple Craftsmanship）的精致微质感**。

### 2.1 色调重构：松烟暖墨 × 器物微层叠 × 四维雅色

1. **拉开“宣纸台面”与“白玉器物”的微明度阶梯**
   * 画布 `--si-bg-canvas` 采用温润松宣白 `#F6F5F0`（侧栏 `--si-bg-side` 取 `#EFECE6`），而核心工作卡、输入框、表格容器 `--si-surface-1` 恢复为纯净暖玉白 `#FFFFFF`，辅以羽毛级双层环境微投影（`0 1px 2px rgba(20,26,24,.03), 0 6px 20px -4px rgba(20,26,24,.035)`）。
   * 夜幕模式告别死灰，采用带极微冷杉底调的**黑曜青墨**（画布 `#101415`、侧栏 `#0B0E0F`、器物浮层 `#161B1D`、顶层微高光 `inset 0 1px 0 rgba(255,255,255,.045)`），深邃温润如黑漆描金。
   * 五级墨色统一校准为微暖松烟墨（`#151918` → `#353C3A` → `#5E6764` → `#858E8B` → `#B2B9B6`），彻底消除冷灰与暖纸的冲突。

2. **从“双色寡淡”扩展为“四维温润雅色（玉釉浅底 + 浓墨正文）”**
   * **主色 · 深松黛青（`#155B52` / 夜幕 `#329688`）**：更纯净深邃的冷翠松青，用于主操作、导航激活态玉轴与本机算力标识；
   * **灵魂点睛色 · 鎏金琥珀（`#B86824` / 夜幕 `#E09648`）**：提亮原“松果赭”的通透度与金石质感，不再发土发暗，用于品牌印枢、AI 灵智洞察徽标、核心焦点高亮；
   * **安心正向色 · 青碧玉（`#1E7D58` / 夜幕 `#4CC392`）**：找回温润不刺眼的青碧色用于“本机脱敏就绪 / 全部响应 / 已核实”，给用户清朗笃定的心理正反馈；
   * **秩序识别色 · 霁蓝与朱砂微釉**：恢复文件格式微徽章（`PDF` 朱砂绯底 `#FCECEB`/`#B42318`、`DOC` 霁蓝底 `#EAF1FA`/`#1D548C`、`XLS` 竹青底 `#E7F5EE`/`#1A6B48`、`AUDIO` 紫檀底 `#F3ECF9`/`#6938EF`），列表一瞥即明。

### 2.2 品牌标识（Logo）重塑：从“水滴松果”升级为「玉衡天枢」

围绕**“商（圭璋契约）· 衡（天平准绳）· 密（内网守护）”**三重精神内核，设计三款几何张力极强、16px～64px 全尺寸锐利的原创标志（可在配套交互预览中实时切换对比）：

| 方案 | 视觉构成 | 精神内核与优势 |
| :--- | :--- | :--- |
| **方案一：玉衡天枢（首推）** | 对称切角八方玉盾外廓（深松黛青）+ 内部精密水平衡梁 + 中央悬垂一枚**鎏金琥珀菱印**（上下双层微透玉釉折面） | “外方盾以守密，内横梁以持衡，中金印以定准”。兼具瑞士几何秩序与东方印信气场，16px 标签页下依然棱角卓然、辨识度极高 |
| **方案二：双阙密卷** | 左右对称开启的松青竹简/城阙折翼（负空间隐含 `S` 与 `I`），正中一道鎏金琥珀枢轴锁扣贯穿 | 直喻“原件深藏双阙之内，金枢脱敏执中”，现代科技感与律所/投行精英气质极强 |
| **方案三：几何松印** | 摒弃软塌曲线，用利落的对称折面构建三叠挺拔松冠（亦如层层核验通过的翼片），底座嵌一枚鎏金方印 | 延续“松青”意象，但由柔弱水滴蜕变为刚毅稳重的建筑感几何徽章 |

### 2.3 图标与微插画体系升级：双色调景深（Duotone Depth）

1. **导航与工具图标“激活态点睛”**：
   * 未选中时保持 `1.65px` 温润次墨色线条；
   * **选中态**不再是冷冰冰的黑字灰底，而是：浅松青玉釉底（`rgba(21,91,82,0.08)`）+ 左侧 `3px` 圆角松青玉轴 + **图标切换为松黛青描边配 `18%` 柔光内填色（Duotone）**，克制却极富精致生命力。
2. **首页四格业务卡片升级为「玉釉微缩器物插画」**：
   * 告别空心火柴盒线条，采用**三层视觉景深**：① `8%` 松青微网格衬底 → ② 带白玉填充与细描边的层叠文档/声波主体 → ③ 鎏金琥珀色的焦点印记/连线与微光圆点，悬停时卡片轻轻浮起 `1px` 并点亮顶部玉青细线。

### 2.4 排版韵律与三大标志性享受级微体验（Signature Moments）

1. **人文书卷标题 × 金融终端级数表**：
   * 欢迎语与登录页主宣言引入可选人文衬线混排（`"Songti SC", "STSong", "Noto Serif SC"` 或字重冷暖节奏对比：问候语轻盈、姓名温润强调），赋予产品独特的儒雅书院气质；
   * **小数尾数降噪美学**：标书报价、限价差额中的整数部分使用 `--si-ink-1` `600` 字重，小数点及 `.00` 自动降为 `--si-ink-3` `400` 字重，千分位一目了然，评标专家一眼抓住核心量级。
2. **首页「灵枢输入舱（Command Atelier）」**：
   * 输入舱顶部内嵌一枚温润的青碧玉实时护盾微胶囊（`● 本机离线脱敏引擎就绪 · 原件不出内网`）；快捷模板标签带上精致双色微图标，选中时呈现柔和琥珀/松青微釉光泽；聚焦时外圈浮现柔和的 `3px` 松青呼吸晕环。
3. **脱敏「X-Ray 透镜切换」与标书「评标指挥席」**：
   * “原文视野 ↔ AI 视野”切换做成丝滑的胶囊滑动透镜，AI 视野下的代号胶囊带锁扣微标与类别淡釉底色；
   * 标书初审顶部的总结横幅采用“白玉浮层 + 左侧 3px 语义玉条 + 右侧环形核对进度仪”，按下 `Y / X` 核对时卡片带清脆的微缩放与状态流转反馈。

## 三、结合代码现状的前端工程可落地性（极低改造成本）

得益于本项目前端前期极佳的架构纪律（全仓颜色字面量 100% 集中于 `frontend/src/styles/theme.css`，组件库覆盖集中于 `skin.css` 与 `common.css`），**完成这套“注入灵魂”的视觉蜕变无需推翻重写业务组件，核心改动仅集中在 6 个收口文件**：

| 序号 | 目标文件 | 改造内容 | 影响范围 |
| :--- | :--- | :--- | :--- |
| 1 | `frontend/src/styles/theme.css` | 升级松烟暖墨、宣白/玉白双层表面、深松黛青 + 鎏金琥珀 + 青碧玉令牌、微器物阴影及夜幕黑曜青墨色板 | 全站自动生效 |
| 2 | `frontend/src/styles/common.css` & `skin.css` | 恢复 `.si-card` 白玉浮层与微阴影、主按钮细腻顶边内高光、页签松青指示线、输入框柔和聚焦晕环、精简档动画修复 | 全站通用控件 |
| 3 | `frontend/src/components/brand/SiLogo.vue` & `public/favicon.svg` | 升级为新标志（如「玉衡天枢」双色多维几何 SVG） | 登录页、侧栏、浏览器标签页 |
| 4 | `frontend/src/layouts/MainLayout.vue` | 侧栏选中态松青玉釉底 + 3px 左侧圆角玉轴 + 激活图标双色调微填色 | 全局导航外壳 |
| 5 | `frontend/src/components/assistant/EntryStrip.vue` & `Composer.vue` | 四张业务卡片升级为带玉釉填色层叠的微缩器物插画；输入舱加入本机脱敏安心状态微胶囊 | 工作台首页与会话 |
| 6 | `History.vue` / 文件列表与 `BidPricing` 金额组件 | 恢复低饱和度四色文件类型微徽标（PDF/DOC/XLS/IMG）；抽离统一金额格式化小组件实现 `.00` 尾数自动淡化 | 历史记录、文件栏、标书报价 |

> 注：前期审核记入 `V34Q-50` 的前端功能性缺陷（如 `WorkbenchHome.vue` 标书点击 404、`BidResults.vue` 卸载轮询泄漏、`SiIsland.vue` 浅色圆点不可见等）在实施上述升级时可顺带一并根治。
