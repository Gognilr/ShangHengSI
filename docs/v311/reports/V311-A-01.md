# V311-A-01 助手会话词条同步

2026-11-11。本机 Docker、pgvector 测试库，外发均用模拟服务。

## 实现

消息选择替换后，将会话文件中未覆盖的同文加入 user 词条，一次重算，沿用中性代号及全部历史映射。发送补旧会话，确认前补新加入文件。明确保留的文字继续保留。预览新增只读 in_files，确认框显示“文件中的同一文字也会替换”；页面已有发送后详情刷新，继续复用。新增 assistant_session_terms 审计只记 count。

实施细节采用先验证消息决定、固定消息代号，再同步文件，避免无效决定参与重算；所有操作与入队在同一事务中完成。中性代号反查复用分配器类别表，允许会话中的口语金额按原文字与原代号持久化。固定助手提示与模板文字命中时返回 422 TERM_IN_PROMPT，提示改选“不替换”。出口复检规则沿用原实现。
