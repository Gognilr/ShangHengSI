# 报价分析页重做：一眼看到问题（V34-B-06e）

状态：Claude Opus 5.5 起草（2026-11-17），**待用户确认**。取代 bid.md 2.4 第 5 项的版式；检查算法不变（B-08b 修识别）。

## 一、要解决的问题

开标现场要回答的只有五件事：每家报了多少？有没有超限价？有没有一家报两个价、大小写不一致或算错？有没有异常低价需要澄清？各家报价之间有没有规律？现在的页面却把 7 列数字、比值曲线、两两比值表、分项对齐表平铺出来，结论要从数字里自己找；识别失败时满屏“未识别 / —”，结论句还写“未见问题”。

**原则：先结论、只摆异常、证据一点即开、明细默认收起。** 没问题的一律只显示一个对勾，不显示数字。这条原则同样适用于结果页其他页签（矩阵见 B-08b 第 6 条）。

## 二、版式（从上到下，一屏内能看完前三块）

```
┌ 结论（一句话，红 / 黄 / 绿）──────────────────────────────┐
│ 2 项需处理：乙 超最高限价 3.2%；甲、丙 分项单价比值恒定（疑似串标） │
└────────────────────────────────────────────────────────┘
 报价位置条  ●甲  ●丙 ●乙 ┊限价     （阴影 = 异常低价区间）
┌ 投标人 ─┬ 投标总价 ──────────────┬ 结论 ──────────────────────┐
│ 甲      │ 1,234,500.00  投标函 P3 │ ⚠ 与丙比值恒定               │
│ 乙      │ 1,548,000.00  开标一览表 P2 │ ⛔ 超限价 +48,000.00（3.2%）    │
│ 丙      │ 未识别  [填写唱标价] [找报价页] │ —                         │
└─────────┴─────────────────────────┴────────────────────────────┘
 需要你处理（3）  ⛔ 疑似否决 → ⚠ 串标线索 → • 需澄清 / 计算问题
   每条：一句话结论（含金额与依据）＋ 原文证据缩略 ＋ 核实 Y / 排除 X
 ▸ 明细（供复核）：分项对齐表、两两比值、报价表合计      默认收起
```

1. **结论句**：只列需要处理的事项，按严重程度排序，带数字；全部正常时写“n 家报价均未见问题”。只要有一家未识别，就先写“丙 未识别出投标总价，报价比较不完整”，不得写“未见问题”。
2. **报价位置条**：沿用 PriceStrip，只保留这一张图：各家位置、平均线、限价线、异常低价区间阴影。少于 2 家有总价时不显示。
3. **各家报价表只留三列**：投标人（录入顺序，不排名，bid.md 一）｜投标总价（右侧小字注明出处页，点击打开原文页）｜结论标签。结论标签取以下几种，最多显示 3 个，其余写“+n”：
   * ⛔ 超限价 +金额（%）、两个以上总价、大小写不一致；
   * ⚠ 比值恒定 / 等差 / 等比（串标线索，注明与哪家）；
   * • 异常低价 −n%（需澄清）、计算错误 n 处、报价表合计与总价不符。
   没有问题的显示 ✓。“比最低价高”“偏离平均”移到明细，鼠标悬停总价时也能看到。
4. **未识别时能补上**：总价格显示“未识别”，旁边两个按钮。
   * **填写唱标价**：现场开标人员手头有唱标记录，直接录入（Decimal）。录入值标“人工填写”，参加比较、限价与规律检查，立即重算（只算本地，不调模型）。识别出的总价也可以点击改正。
   * **找报价页**：列出该家含“开标一览表 / 投标函 / 报价 / 大写”等字样的页，按命中多少排序，点击即看页图。
5. **需要你处理**：只列报价类问题与线索，顺序为疑似否决 → 串标线索 → 需澄清 / 计算问题。每条一句话写清结论、金额与依据，附原文证据缩略（大小写不一致把两处原文并排；比值恒定给出 5 项以上分项的比值小表）。可以直接核实（Y）或排除（X），与“待你处理”清单同一数据。原来的“确认本机计算的 n 条”并入这里。
6. **修正后报价**（只在有计算或大小写问题时出现）：按招标文件约定的修正原则给出“修正后总价”，常见原则是大写为准、单价为准（《评标委员会和评标方法暂行规定》第十九条，以招标文件为准），并标注“供评标委员会参考，须投标人确认”。修正后若超限价，另起一条提示。
7. **明细（供复核）默认收起**：分项对齐表只高亮异常格；两两比值表与比值曲线只在找到规律时自动展开对应那一对。

## 三、数据与接口

* 人工填写的总价：每家一个值加“人工填写”标记，与报价分析结果同样加密存储（Alembic 迁移）；`PUT /bid/{id}/bidders/{bid}/total`，校验 owner，只在待核对阶段可改，改后重算报价分析与相关问题。审计记录不写金额。
* 找报价页：本地检查时顺带记下候选页（每家最多 10 页），不另跑 OCR。
* Word 报告的报价分析一节按同样顺序写：结论 → 各家总价与结论 → 需处理事项 → 明细附录；人工填写的总价注明来源。

## 四、不做

不按价格排序，不给出“推荐”“合理价”；不新增页签或菜单；不改相似段落等其他检查。
