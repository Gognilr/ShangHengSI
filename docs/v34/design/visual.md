## 〇、一句话与五条原则

**整个系统是一张连续的纸：内容直接写在纸上，层次靠细线、留白和字重，不靠灰底上贴白卡、不靠光。**

1. **一张纸。** 主区域只有一个底色，内容区与背景是同一层。分组用 1px 细线和留白；只有“独立的、可以拿走的对象”（一条问题、一家投标人、一份文件正文）才有边框，且边框内外同色。
2. **墨为主，色为点。** 屏幕上 95% 是墨色的五个深浅。主色“松青”只出现在六处、暖色辅助色“松果赭”只出现在四处（第二节）；状态色只出现在一个 6px 圆点或一个数字上，不铺成色块。
3. **阴影只属于浮在纸上的东西。** 下拉、弹层、对话框、抽屉，以及首页那个输入框。其余一律无阴影、无辉光、无渐变。
4. **静止即安静。** 静止的界面没有任何渐变与光效；动的东西只在“系统正在工作”时出现，颜色由松青与松果赭派生（冷暖交替的多色），不出现别的色相。
5. **为长时间阅读而设计。** 正文对比度不低于 WCAG AA（4.5:1），阅读区不用纯黑纯白，行长、行高沿用排版升级方案（docs/design/shangheng-si-typography-upgrade.md）。

与现状最大的不同：去掉氛围光、辉光、面板阴影与“灰底白卡”；主色由亮蓝改为松青，并配暖色辅助色松果赭；侧栏选中改为中性灰底；表格去掉表头灰底与固定列；状态标签由彩色胶囊改为“圆点 + 文字”；品牌标识重新设计为“冷暖两笔”。

## 一、品牌标识

### 1.1 现行标识的评价（frontend/src/components/brand/SiLogo.vue）

| 方面 | 问题 |
|-|-|
| 颜色 | 深海蓝 → 蓝 → 青三色渐变，是全系统“颜色过渡明显”的源头之一；夜幕下深海蓝看不见，须把渐变起点换成主色，同一标识两种长相 |
| 细节 | 斜体 S + 左侧三个像素方块 + 中心白色四角星芒，三种语言叠在 24px 里；16px（标签页图标）下方块与星芒糊成噪点 |
| 含义 | 像素点与星芒表达的是“科技、AI”，偏消费级；没有表达“商务、权衡、公正”，也没有表达“脱敏” |
| 一致性 | 斜体、渐变、圆头粗线与本次“稳重、细线、单色”的界面语言不在一个调上 |

### 1.2 三个方案（预览“设置 · 品牌标识”页，含侧栏展开、窄栏、标签页 16px、登录页，浅色与夜幕）

2026-11-15 用户意见：纯方块的方案不要；标识要原创、简洁、有记忆点，用新主色“松青”与暖色辅助色“松果赭”，不得模仿任何现有品牌的标志与配色组合。上一稿的三个方块 / 方印方案已删除。

共同约定：**不用底板、不用渐变**；图形以松青为主体，**只有一笔是松果赭**（冷暖一对即品牌识别）；夜幕下松青换成较亮的一档（`--si-logo-a`），形状不变。字标“商衡”600、字距 0.14em，后接细竖线与等宽小字“SI”。

| 方案 | 图形 | 含义 | 优点 | 风险 |
|-|-|-|-|-|
| **一 · 权衡（推荐）** | 一杆秤：一道松青横杆，左侧三分之一处一根向上的提纽，右侧垂下一枚松果赭的秤砣 | “权”的本义是秤砣，“衡”的本义是秤杆——“权衡”二字直接成图；杆秤又是旧时商铺的信物，对应“商”；提纽偏在一侧而杆仍水平，正是“公正” | 四笔成形，16px 下仍是“一横、一竖、一个暖点”，轮廓独特；中文语境一看就懂，别的行业用不上；冷杆暖砣天然承载双色 | 图形偏扁，与字标并排时须按视觉重心对齐（图形整体下移 1px） |
| 二 · 松针 | 松树“二针一束”：两枚等长的细长针叶自同一点向上分开，基部一段松果赭的针鞘 | 两针等长即“衡”；松，取其常青与守护；形似准星、圆规，有“精确、核对”之意 | 最轻、最挺，现代感最强；与“松青”之名互相解释 | 小尺寸下略像幼苗，容易被读成环保、农业类品牌；“商”的含义弱 |
| 三 · 松鳞 | 松果的外轮廓（上尖下圆，近似一面盾），内有一道鳞片折线，底部一片菱形鳞填为松果赭 | 守护的外形里，有一片被遮住——即脱敏；松果也是暖色辅助色的出处 | 含义最贴合“脱敏” | 轮廓接近水滴 / 定位标，线条最多，16px 下不如前两者干净 |

**用户 2026-11-15 已定：方案三“松鳞”。** 完整版（≥ 32px：登录页、报告封面）为外形 + 两层鳞线 + 一片松果赭鳞；小尺寸版（≤ 26px：标签页 16px、侧栏、窄栏）只留外形与那片暖色鳞并加粗线条（见预览“设置 · 品牌标识”）。方案一、二仅作曾考虑的方案记录；启用前做一次商标近似查询。

### 1.3 落地

* `SiLogo.vue`：重画为“松鳞”两档 SVG（≤ 26px 用小尺寸版）（去掉 `linearGradient`、`--si-logo-start` 与夜幕特判），两种颜色取 `--si-logo-a` 与 `--si-accent`；`hero` 尺寸图形 64px、字标 34px。

* 登录页短横线、报告封面条不再用渐变，改单色松青。

## 二、色彩

### 2.1 主色：松青；辅助色：松果赭

2026-11-15 用户意见：主色不再用蓝色，要有自己的品牌特色，取“松青”（青松、松针的深青绿）；另配一个暖色辅助色。

**主色候选**（都偏深、低饱和；白字在按钮上、主色文字在纸上均达 AA；预览右下角可切换，全站随之变化）：

| 候选 | 浅色：按钮底 / 文字 / 按下 | 夜幕：按钮底 / 文字 / 按下 | 白字对比度（浅 / 夜） | 气质 |
|-|-|-|-|-|
| **A 松针青（推荐）** | `#1F5F58` / `#1B564F` / `#184C46` | `#2F8177` / `#7FCDBF` / `#296F66` | 约 7.4:1 / 4.6:1 | 青与绿各半，沉静、有分寸；与红、黄语义色和暖色辅助色都拉得开 |
| B 苍松绿 | `#2B5D45` / `#265540` / `#214A37` | `#3B7F60` / `#8FD0AE` / `#326E53` | 约 7.6:1 / 4.8:1 | 更绿、更“松”；但最容易被读成“成功 / 通过”，也偏金融、环保 |
| C 黛松青 | `#1D5566` / `#194C5C` / `#164453` | `#2E7A90` / `#86C9DC` / `#27697C` | 约 8.3:1 / 4.9:1 | 偏青蓝、最冷静；与原来的蓝过渡最平顺，但“松”的特色最弱 |

推荐 A：它既明确不是蓝，也不是会被误读为“通过”的正绿；与松果赭的冷暖对比最好看。下文令牌表按 A 填写，选 B 或 C 时只换这五个值（`--si-blue`、`--si-blue-ink`、`--si-blue-press`、`--si-blue-tint`、`--si-brand-2`）。令牌名 `--si-blue` 建议随实施改名为 `--si-brand`，旧名在 C 块留一行映射。

**暖色辅助色：松果赭** `#9C5B34`（夜幕 `#D39A6A`；纸上作文字约 5.2:1），另有浅一档的琥珀 `#C99A5B`（夜幕 `#E6BE8A`）只用于动效。

**冷暖各有含义，形成品牌特色**：松青＝本机、已保护、可以确定的；松果赭＝模型、进行中、需要人核实的。所以护盾胶囊、本机计算、主按钮是松青；“AI 建议 · 请核实”的小图标、等待动效里的暖点、标识的秤砣、入口线描图里的那一笔是松果赭。松果赭**不作状态色**（不表示警告），不作大面积底色，不作按钮。

### 2.2 颜色出现在哪里

**松青六处**：① 标识主体；② 每屏至多一个的主按钮与发送按钮；③ 链接与行内文字按钮；④ 键盘焦点外环、输入中的选区；⑤ “已在本机保护”的护盾胶囊与本机保护指示点；⑥ 进度（进行中的圆环、步骤条当前步、入口格悬停线）。

**松果赭四处**：① 标识的一笔；② 首页四张入口线描图里的一笔；③ “AI 建议”分区的小图标；④ 等待动效（与松青混排）。

**不再用品牌色的地方**：侧栏选中、表格当前行、页签下划线、分段控件选中、文件类型徽标、“新建会话”、统计数字、卡片悬停——全部中性墨色。

**语义色的调整**（避免与松青、松果赭相撞）：

* **成功 / 已完成不再用绿色**：改为“墨色对勾 + 文字”（`--si-ok` 取墨色二级）。绿色与松青太近，且“已完成”本来就不该比“有问题”更抢眼；这也顺带消除了“绿色＝审核通过”的误读。
* **警告由琥珀橙改为偏黄的赭黄**（`#C28A00`，文字 `#7D5F00`），与松果赭在色相上分开；警告永远带圆点或图标，不单靠颜色。
* 危险红不变（`#C4262E`）。低风险、中性仍为灰。
* 替换类别色 `--si-k-*` 中“地址”一类原为绿色（`#2E7D4F`），与松青接近，改为橄榄 `#6B6B2A`（底 `#F1F1E2`）；其余类别不变。

## 三、表面与层级

由五层收为三层：

| 层 | 底 | 边界 | 用于 |
|-|-|-|-|
| 纸 | `--si-bg-canvas` | — | 主区域及其上的一切内容：标题、列表、表格、表单、面板 |
| 侧 | `--si-bg-side` | 右侧 1px `--si-hair-faint` | 侧栏；登录页左半 |
| 浮 | `--si-surface-pop` | `--si-shadow-3`（自带 1px 边） | 下拉、弹出框、对话框、抽屉、提示；`--si-blur` 毛玻璃取消（纯色更稳，也省性能） |

规则：

* **`.panel` 不再是卡片**：背景透明、无边框、无阴影、无圆角、内边距 0；两个面板之间用 32px 留白 + 1px `--si-hair` 分隔（`.panel + .panel { margin-top: 32px; padding-top: 32px; border-top: … }`）。`el-card` 同样处理。改 styles/common.css 第 38～39 行与 skin.css 的 el-card 段。
* **`.si-card`（对象卡）**：只用于问题卡片、投标人卡片、选项卡片。背景透明（与纸同色）、1px `--si-hair`、圆角 10px、无阴影；可点击的悬停为 `--si-hover-bg` + 边框 `--si-hair-strong`，**不上移**。
* **区块标题**：一行小标题（`--si-font-overline`，见第四节）+ 其下一条线；列表、表格的第一条线用 `--si-hair-strong` 或 `--si-hair`，行间线用 `--si-hair-faint`。
