## 〇、范围与规则

**来源：** 2026-11-15 与用户的讨论：标书比对能力、首页与导航别扭、颜色过渡不稳重、快捷标签弹窗、历史记录横向滚动、品牌标识。

**目标：**
1. 导航“一事一入口”：侧栏 工作台｜（文件审查）文件审核、标书初审｜（工具）会议纪要、翻译｜历史记录、搜索；高亮不再跳。
2. 视觉第三版“素纸”：全站一张连续的纸；主色松针青 + 辅助色松果赭；新标识“松鳞”；欢迎语一句话、常规字重。
3. 新菜单“标书初审”：招标方对 3～5 家投标文件做资格、符合性审查与串标线索初审，整体设计、一次实施（V34Q-02）。

**不做：** 打分、排序、推荐中标人；印章图像识别；更换本地模型或技术栈；新增依赖；改动现有脱敏、还原、出口复检对审核任务与会话的行为（标书初审的片段脱敏复用同一引擎）。

**规则：**
* main 上串行，一次一个任务，**每个任务单独开一个新会话**；提交说明以任务编号开头（英语或日语），小步提交，`git add` 只暂存本任务文件。
* Claude 与 ChatGPT 谁有额度谁做。下表每个任务给两侧各一个模型与推理强度，任选其一；Sol 6.1 = GPT-6.1 Sol，Terra = GPT-6.1 Terra。先用表里的强度，同一验收点两次不过再升一档。涉及脱敏、出口的任务（B-05）由另一侧交叉复核。
* 交接只靠仓库：开工读 CLAUDE.md（Codex 另读 AGENTS.md）、本文件第〇节与该任务一节、对应设计文档章节与问题条目、上一个任务的报告与 `git log`。结束时在状态列写“已完成（日期，执行者，报告路径）”并提交。
* 视觉以 design/visual.md 为准：十六进制颜色只写在 theme.css；A 批完成前，docs/design/frontend.md 仍是旧版，Z 时以 visual.md 替换为第三版。
* 前端改动用浏览器检查（http://localhost:5173），浅色、夜幕与三档特效各看一遍，截图只留在会话里。不为样式与措辞加测试（CLAUDE.md）。
* 真实标书只在本机评测（B-08），原文、名称、金额、密码不进仓库、对话与日志；真实模型调用开工前停下，告诉用户调用次数，由用户录入密钥。
* 新问题记在 open_questions.md（V34Q-11 起）。报告放 docs/v34/reports/，每份不超过一页，末尾写建议的 SPEC / CLAUDE.md 改动，由 V34-Z 合并。整仓全量只在 V34-Z 跑一次。
