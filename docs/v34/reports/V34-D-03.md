# V34-D-03 文字页受限 text 兜底、跨页续表、PDF 页眉页脚

状态：已完成。执行：Claude Opus 5.5，2026-11-19。

## 一、做法

* **受限 text 兜底（`parsing/pdf.py` `_text_tables`）：** 文字页线框策略无表时，用 pdfplumber text 策略再检一次；只保留前 5 行内含两类表头（单价 / 数量 / 金额 / 合计等，`header_kind`）且无纯数字的表头行起、到连续两行只剩一格为止的行，并要求至少 3 列各有 2 个以上纯数字单元格，否则整张丢弃。表上方的标题、下方的说明仍是段落。
* **跨页续表（`redaction/tables.py` `continued_tables`）：** 前表是本页最下面的表、续表是下一页最上面的表；列数相同，各列左边界与表格左右边界对齐（容差 max(6 点, 表宽 2%)）；首表前 20 行内有单价或金额表头；续表开头无表头，或开头几行与首表表头行（及其上下一行）逐列相同，这些行去掉不计。可连续多页。`checks/amounts.py` 的 `_scan_tables` 按此拼成一张逻辑表（L-01～L-03、合计、标书报价、consistency、references 都经过它），loc 不变；结果中的行位置写回原表与原行号（如“F1-PG2-T1 第 3 行”）。解析 warnings 加“第 X–Y 页表格按续表合并核对”。不加字段、不迁移：`CheckNode` 增加内存字段 bbox，审核与标书读节点时带上。
* **页眉页脚（`_mark_running`）：** 文字页段落与 OCR 块，完全位于页顶 / 页底 8% 带内，去空白、数字归一化后在至少 3 页且至少半数页重复，标 part=header / footer。表格单元格不参与。
* **未覆盖：** 标书投标文件的延后 OCR 页（`ocr_pages`）不做页眉页脚标记，也不加续表 warning；续表核对在读表时进行，不受影响。标书本地检查本来就读页眉（part ≠ comment），不影响结果。
