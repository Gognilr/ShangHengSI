# V34-A-04 工作台首页

日期：2026-11-16　执行：Claude Opus 5.5　依据：PLAN V34-A-04、visual.md 7.2 与第五节、V34Q-01、06、09

## 改动

* **欢迎语**（Assistant.vue）：问候、称呼与问句合成一个 `<h1>`，一行一句（“早上好，管理员，新的一天想先从哪项工作开始？”），26px、常规字重、墨色、字距 .03em（`--si-font-greeting`），与输入框左对齐。去掉首页的“直接提问 / 全面审核”分段。
* **入口格带**（新 components/assistant/EntryStrip.vue）：四格共线，上沿粗细线、格间淡竖线，无底色无圆角无阴影；每格 72×44 墨线小图（各有一笔松果赭）、等宽序号 01～04、标题、两行说明、一行实时状态。悬停整格浅底、上沿 2px 松青线自左展开、标题旁滑出箭头；特效关闭时由 motion.css 取消过渡。没有权限的格不显示，其余等分；窄于 720px 时两列。
* **实时状态与“继续上次的工作”**（新 components/assistant/WorkbenchHome.vue）：取历史记录、会议纪要、翻译各第一页。文件审核：“n 份审核中 / n 条待处理 / 上次：周一 / 拖入文件即可开始”；会议纪要：“上次：今天 10:20 会议名”或转写是否启用；翻译：“本地模型 · 不外发 / 云端 · 脱敏后发送”。下方最多 3 行列表行（名称 · 类别与状态 · 时间），右上“全部历史”（V34Q-15）。标书初审格在 B-01 前只占位（V34Q-14）。
* **快捷标签**（TemplatePicker.vue、Composer.vue）：前缀“常用”；30px、透明底细边，选中为中性选中底（不变蓝）；删掉选模板时自动打开文件窗口的一行；模板行就地写“说明 · 需要 n～m 个文件”，文件不够时显示“加入文件”文字按钮；悬停说明删去。
* **输入框**：16px 圆角、`--si-field` 底、`--si-shadow-composer`，聚焦只把边框加深为 `--si-ink-4`，不再变蓝；模板标签改中性底。
* **会话工具条**：没审核过、也没打开过审核视图的会话只放“全面审核 →”文字按钮；审核过或打开过后才显示“直接提问 / 全面审核”两个页签。只加了文件、还没提问的会话（首页样式）在输入框下方右侧放“对已加入的文件全面审核 →”。首页与该状态的外层不再有卡片框。

## 验证

`npm run build` 通过。浏览器（localhost:5175，1366×640）：首页一屏放下欢迎语、输入框、常用标签、格带与“继续上次的工作”；依次点四个标签，文件窗口调用 0 次，模板行文字正确，点“加入文件”调用 1 次；悬停格带线条、浅底、箭头正常；夜幕、特效关闭各看一遍；从首页打开会话 → “对已加入的文件全面审核 →” 进入审核视图，工具条出现两个页签、侧栏高亮文件审核；在页面中去掉 use.review 后首页只剩会议纪要、翻译两格且等分（只有审核权限的人进 `/assistant` 已由 A-03 转到 `/review`）。控制台无报错。
