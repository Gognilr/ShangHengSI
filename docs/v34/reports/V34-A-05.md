# V34-A-05 入口页与历史记录

日期：2026-11-16　执行：Claude Sonnet 5.5　依据：PLAN V34-A-05、visual.md 7.4、7.6、7.7、V34Q-07、08

## 改动

* **入口页统一**（common.css、Translate.vue、Meeting.vue、MeetingRecorder.vue）：`.entry-title`、`.entry-lede` 改左对齐；翻译的“译成”选项行、“或粘贴文字翻译”、会议的上传进度与现场录音按钮都靠左；“最近的翻译 / 最近的会议”标题行右侧加“全部历史”，与文件审核首页（Review.vue，A-03 已是此套路）一致。拖入区在 A-01 已是透明底虚线，无灰底白卡反差。
* **历史记录**（History.vue、utils/time.ts）：去掉外层面板；页标题“历史记录”+“共 n 条 · 仅本人可见”；筛选行只剩搜索框与日期范围，搜索输入停顿 300ms 即查（回车、清除、选日期立即查），去掉“查询”“新建审核”按钮。表格 10 列并为 7 列（名称、状态、高风险、待处理、最近活动、保留至、操作），名称列第二行小字“类型 · 文件类型 · 立场”；不再有固定列；时间到分钟（新增 `formatDateTimeMinute`）；状态为“圆点 + 文字”（审核中为松青空心环，已审核为墨色点）；文件类型徽标去色，30px 细线方块；0 与“—”用 `--si-ink-5`，高风险、待处理大于 0 才着色；分页右对齐，去掉左侧“共 n 条”（挪到标题旁）。

## 验证

`npm run build` 通过。浏览器中 1280、1366、1920 宽下表格宽度分别为 960、1046、1240，内容宽等于可视宽，无横向滚动条，无固定列阴影；翻译、会议纪要首页左对齐、无灰底白卡；控制台无报错。
