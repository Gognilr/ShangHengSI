# V34-A-06 结果页、对话页、设置页去卡片化

日期：2026-11-16　执行：Claude Sonnet 5.5　依据：PLAN V34-A-06、visual.md 第五节、7.3、7.4、7.8、V34Q-08

## 改动

* **设置页**（SettingsLayout.vue）：去掉外层 `.panel` 大卡；左列导航 200px、透明底，与右列之间一条 `--si-hair` 竖线；分组名改 `--si-font-overline`；右列无左右卡内边距（只留与导航之间 32px）。各子页的 `.panel` 早在 A-01 的 common.css 中变为无框，不再单独改。
* **问题卡片**（FindingCard.vue）：透明底、1px 细线、10px 圆角；去掉左侧 3px 等级竖条与彩色胶囊，改“6px 圆点 + 等级文字”（高风险、中风险分别用危险、警告色，其余次要色）；悬停为 `--si-hover-bg`、不改阴影；选中边框 `--si-ink-3`，去掉蓝框与外圈阴影；已采纳、已忽略不再变竖条色（沿用降亮与灰度）；“可替换措辞”与“讨论修改稿”块统一为 `--si-surface-2` 底、无蓝；“讨论稿”标记选中为中性底。
* **问题栏**（FindingsRail.vue）：不再是带框带底的卡，只在左侧留一条细线，与纸同色。
* **对话气泡**（MessageItem.vue、ChatPanel.vue）：用户消息改 `--si-surface-2` 底、12px 圆角（原为浅松青）；引用条款块改中性细竖线与 `--si-surface-2` 底。

## 验证

`npm run build` 通过。浏览器中看过设置页“个人”（浅色），无外层卡，导航与右列只有一条细线。
