# V34-A-01 令牌、语义色与外壳

日期：2026-11-16　执行：Claude Opus 5.5　依据：docs/v34/design/visual.md 第二、三、四、五、六节，V34Q-08

## 做了什么

* **theme.css**：A、B 两块按 visual.md 2.3 换值（纸 `#FBFBFA`、夜幕中性炭灰 `#15171A`、`--si-surface-1` 与画布同值）。主色改名 `--si-brand`（松针青），C 块留 `--si-blue: var(--si-brand)` 旧名映射；新增 `--si-blue-press`、`--si-brand-2`、`--si-accent`、`--si-accent-2`、`--si-blue-tint`、`--si-select-bg`、`--si-hover-bg`、`--si-logo-a`、`--si-shadow-composer`、`--si-font-greeting`、`--si-font-overline`。删除 `--si-cyan`、`--si-indigo`、`--si-ambient`、`--si-glow-blue`、`--si-blur`、`--si-panel-shadow`、`--si-shadow-1/2`、`--si-brand-navy`、`--si-brand-gradient`、`--si-brand-blue` 和特效档的毛玻璃块。语义色：成功改墨色、警告改赭黄、“地址”类别改橄榄；`--si-ai` 指向松果赭。字号、圆角按 4.2、4.3 改值。
* **skin.css**：主按钮去辉光，悬停用 `--si-blue-press`；默认按钮改透明底；输入框聚焦去掉蓝色外发光（边框变 `--si-ink-3`）；弹层、对话框去毛玻璃；表格透明、表头去底色、表头下一条强线；页签墨色下划线，当前项 600；标签改为透明底，“圆点 + 文字”；提示条透明底加细线；`el-card` 去卡片化；审阅光带换为松青 → 浅松青 → 琥珀 → 松果赭，关闭档不留静止的彩色线。
* **common.css**：`.panel` 不再是卡片（面板之间 32px 留白加一条细线）；`.si-card` 透明、悬停不上移；`.stat` 去框改竖线；`.si-drop` 透明底，拖入中为松青实线；`.list-row` 44px 加行间细线；页面内边距 32/40/56，标准列 800px，宽列 1240px；新增 `.si-overline`。
* **组件**：SiSegmented 选中块去阴影；EmptyState 改为 32px 淡墨图标、左对齐（表格内居中）；StepBar 改为上下细线的一行步骤，当前步为松青实心序号。
* **外壳 MainLayout**：去氛围光；侧栏选中改为中性灰底加字重 600（无竖条、图标不变色）；“新建会话”与菜单项同形；默认宽 240px；用户首字圆改中性。近期会话、设置左栏的选中项也同步改为中性。
* **删除令牌的其余引用**：SiLogo（暂改为单色松青，A-02 重画）、Login、SiIsland、SiThinkingDots、ReviewCeremony、ReviewNew、ConfirmCanvas、TranscriptEditor 只换掉已删除的令牌，不改布局。
