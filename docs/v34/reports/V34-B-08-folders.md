# V34-B-08 文件夹筛选同步与展开收起附记

日期：2026-11-17　执行：Codex　状态：实现与功能核对完成。

用户追加：已归档的文件夹与右侧项目列表筛选不同步，一级目录需可展开、收起。口径见 V34Q-35。

## 改动

* `backend/app/bid/router.py` 抽出列表筛选条件供列表与 `/bid/folders` 共用；`folders.py` 按当前搜索、分类、阶段、开标日期统计目录计数，保留空目录。本人隔离与父目录包含子目录的规则沿用。
* `frontend/src/api/bid.ts` 传递计数筛选；`views/Bid.vue` 同次读取列表与目录后一起更新，地址前进 / 后退还原控件、选中目录与列表。无结果仍可继续筛选；计数 0 明确显示，悬停 / 聚焦不隐藏。
* 文件夹有子目录时显示独立箭头按钮，一级与二级均可收起；点击目录名称筛选列表，点击箭头只折叠。沿用视觉令牌，无新依赖。
