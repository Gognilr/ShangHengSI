# V34Q-50 第 3 项 · 招标文件模型补充采用中性脱敏

2026-11-18，Codex。

- 招标文件模型补充使用既有中性脱敏模式。开启系统日期平移时，招标条款日期仍保留原值。原有百分比照常保留，金额仍替换为代号，正文不追加合同总价比例换算。模型引文中的金额代号在本机还原后定位原文。
