# V34-A-03 导航一事一入口与文件审核页

日期：2026-11-16　执行：Claude Opus 5.5　依据：PLAN V34-A-03、visual.md 第六节与 7.4、V34Q-01；用户追加：设置移入账号菜单（V34Q-12）

## 改动

* **侧栏 MainLayout.vue**：菜单分四段——工作台｜“文件审查”文件审核｜“工具”会议纪要、翻译｜历史记录、搜索；分组名用 overline 小字，收起窄栏时变为短细线，历史记录前一条细线。“智能审核”改名“文件审核”，指向 `/review`。工作台只对有“智能助手”权限的人显示（只有审核权限的人进 `/assistant` 会被转到 `/review`）。
* **高亮规则**：`/review`、`/review/*`（旧审核任务页，原归历史记录）、发起过审核或在本页打开过审核视图的会话 → 文件审核；其余工作台页 → 工作台；设置页、不存在页不选中菜单。会话内“直接提问 / 全面审核”切换不再跳动（sessions 仓库新增 `markReview / isReview`，依据 run_count、审核中与本页打开过审核视图）。
* **设置移入账号菜单**：侧栏底部的“设置”删去，账号菜单为 设置｜外观、修改密码｜退出；在设置页时用户名一行显示选中底。
* **新页面 views/Review.vue（`/review`）**：标题“要审核什么文件？”、一行说明、拖入区（点选、拖入、Ctrl+V 粘贴，可多份）、“最近的审核”5 行（审核中 / 已审核 n 轮 / 状态 · 待处理 n · 时间）与“全部历史”。上传时才建会话，进入 `/assistant/:id?mode=review`，之后流程不变。
* **路由**：新增 `/review`；`/assistant?mode=review` 与无 task 的 `/review/new` 重定向到 `/review`；`homeFor` 对只有审核权限的人返回 `/review`；须改密时不转走，避免与守卫来回跳。
* **工作台 Assistant.vue**：首页删去审核分段与拖入区（只剩提问，A-04 再改版）；会话内的页签不变。
* **改名**：权限点 use.review 名称、模型编辑“可用于文件审核”、模型测试提示、外发记录的用途标题（llm_calls.task_title）改为“文件审核”；全局搜索的页面、操作项指向 `/review`；历史记录“新建审核”指向 `/review`。

## 验证

`npm run build` 通过；`tests/test_a03_outbound.py` 2 项通过（用途标题断言随改名修改，属有意改变）。浏览器（localhost:5174，1366×720）：`/assistant?mode=review` → `/review`；在 `/review` 粘贴一张图片后进入会话审核视图，高亮文件审核，切到“直接提问”不跳；回到工作台首页高亮工作台；`/review/new` → `/review`；历史记录高亮正确；账号菜单“设置”进入 `/settings/personal`；收起窄栏与夜幕下分组短线、选中正常；控制台无报错。
