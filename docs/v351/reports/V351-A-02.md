# V351-A-02 备份与恢复原件一致性

2026-11-25 · Codex 自审 · Q-02

- 备份从同一份数据库转储读取所需文件键，核对实际写入的归档成员后发布、生成校验文件并轮换。恢复预检采用相同口径，缺件在脚本停服前拒绝，切换后保留核对。更新对应运维说明。
- 未清理的文件以原件或已登记录音回放副本为准，已登记的转换件必须存在。旧版缺少可选列时仍可读取，已按保留期清除的原件不要求复原。沿用版本 1 归档。
- 断网 Docker Python 3.12、pgvector 空测试库。备份与恢复专项 14 项通过，回读退出码 0。使用真实 pg_dump，文件枚举后调用正常任务删除，备份失败且原有备份和 SHA-256 文件字节保持一致。缺转换件的 tar 在预检被拒，现用文件未变；完整包通过实际 pg_restore、换卷、归属及解密核对。
- 同一环境用虚构资料生成 0025 和 0051 的真实转储和版本 1 归档。0025 通过缺省可选列的预检，0051 执行恢复、换卷并迁至 0056 后校验原件、账号归属，演练退出码回读 0。完整发布包和运维脚本演练留在 V351-Z。
