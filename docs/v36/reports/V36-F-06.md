# V36-F-06 会议纪要与翻译

2026-11-27 · Claude Sonnet · 停点为截图交用户

## 交付

* **会议入口**：新增 `VoiceBand.vue`（声纹带，指针靠近的柱子抬高变深，录音中变实时声波）。`MeetingRecorder.vue` 改为声纹带加中间的录音大按钮，上传录音合进同一张卡的拖放行（`Meeting.vue` 经插槽放入）。录音中整页只留大号计时、实时声波、暂停、打点、结束并转写。本机转写未启用时整张卡变灰。最近的会议改用 `TripTimeline`。
* **会议页**：新增 `SpeakerLanes.vue`，每位发言人一条泳道，播放头贯穿，点任一段跳到那句话；取代原单条说话活动条。逐字稿放进青色地带，纪要放进紫色地带。发言人圆标与泳道同色。工具条标题下加时长与发言人数。
* **翻译入口**：新增 `TransLine.vue`。两种方式是一个开关，下方往返线当场变色：本机整条青色三站，云端出现遮住、复检两站且模型段为紫。目标语言、拖放与粘贴、最近的翻译（时间线）放在其下。
* **翻译页**：`TranslationView.vue` 每段左缘加刻度（已译站色实线、生成中闪烁、待译占位色；本机青、云端紫），顶部提示改 `SiNotice` 注意语气；本机翻译慢的提示同样改 `SiNotice`。
* 取舍记在 V36Q-19（直接开始录音、方向键、待办、云端时间说法）。
