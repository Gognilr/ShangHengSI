# V36-B-01 合同对比与多稿对比

2026-11-27 · Codex · 停点为截图交用户

## 交付

* `review/drafts.py` 在去空白前识别手写编号，金额、比例、期限和数量变化按修改算。替换块按 0.6 门槛做顺序不交叉的最高总相似度配对，补上短段换位及甲乙方名称互换。编号顺延在列表合并，增量复审逐处取位置。
* `parsing/docx.py` 更新为 `docx-4`，读入 Wingdings 勾选符号。合同对比按分区对齐正文、表格、页眉页脚和文本框，列出隐藏与显示变化，提示稿件中未对比的内容。留痕在同一处按片段标出，含末段留痕删除和 Word 记录的隐藏属性修订。
* `review/contract_compare.py`、`router.py` 增加重传两稿后直接生成的 Word 对比表，含两稿位置、原文、高亮和留痕。接口要求 `use.review` 与 `use.export`，请求和 Word 成品驻留内存，无业务记录。
* 合同对比页、`DiffRail.vue` 及对应接口类型显示分区、编号、隐藏文字和未对比范围。会话中只有标点与空格默认收起。会话分区和留痕范围记入 V36Q-17。

## 验收

* Docker Python 3.12、pgvector 测试库。对比、DOCX 解析、管线、锚点及增量复审共 `143 passed in 74.72s`，最后清理差异片段逻辑后复测对比及增量复审 `13 passed in 23.78s`。两次退出码均回读为 `0`。
* `npm --prefix frontend run build` 显示 `✓ built in 1.57s`，退出码 `0`，构建提示原有的大块体积警告。
* 使用虚构 Word、独立本机库及本机 API。在合同对比和会话变化栏各截浅色、深色 × 1366、1440，共八张。浏览器验证键盘定位、重选、空结果和下载。下载样本有 15 条差异、7 列与 34 段高亮。对比、导出和走查没有调用真实模型。
