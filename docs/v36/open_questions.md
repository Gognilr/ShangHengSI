# V3.6 问题与待定事项

编号 V36Q-01 起。每条写：问题、做法、谁定的。

### V36Q-01 往返线取代步骤条与任务状态色

* **问题**：frontend.md 第九节步骤条与第十二节任务状态各有一套画法，各页还自写进度条。
* **做法**：统一为 SiTrip。规则是“颜色说在哪里，光圈说怎么样”：
  * 本机站为青，模型站为紫；
  * 进行中加呼吸光圈，等你与被拦截用琥珀，失败用红。
  * 天蓝不再表示进行中，只用于“低”等级与说明。
* **出处**：Opus 起草（规范草案第二节），待用户确认。

### V36Q-02 揭幕滑块的对齐与对照视图的边界

* **问题**：原文与代号长短不同，两层直接叠放会换行错位。滑块的右层由前端按实体位置显示代号，需要说明它和 frontend.md 13.7 的关系。13.7 规定外发栏只显示后端返回的内容。
* **做法**：
  * 每个遮住处用同一个网格单元叠放原文与代号，宽度取两者中较宽的，两层只切换可见的那一个，换行因此一致。
  * 滑块与现有的“模型将看到的”视图一样属于对照视图，只用于阅读。“将要发送的”文本与实际外发仍以后端返回为准。
  * 扫描件显示原件页图时没有逐字对应，退回二选一开关。
* **出处**：Opus 起草，待用户确认。

### V36Q-03 主图需要的后端改动

* **问题**：哪些主图要后端配合，会不会因此加表。
* **做法**：不加表，只做以下三项：
  1. 模型页聚合接口：llm_calls 本月按模型与上海时区自然日分组，给出调用数、失败数、拦截数、中位耗时、按 purpose 的计数、费用合计（V36-F-02）。
  2. 数据页按到期日计数的接口，只给件数（V36-F-07）。
  3. 列表类接口为迷你往返线补外发策略、轮次状态等缺少的字段（V36-F-01）。
* **约束**：只给计数与金额，不给任务名、用户名或任何内容，管理员看不到他人任务；权限与所在设置页相同。
* **出处**：Opus 起草，待用户确认。

### V36Q-04 标书项目页的主图

* **问题**：方案稿曾画“投标人线索关系图”，与 2026-11-20 定位收缩撤下的串标关系图冲突。
* **做法**：
  * 主图改为“开标桌”：投标人卡片一排，有严重问题的卡加红线和计数。
  * 两家之间的线索仍用现有的相似段落位置条和原件并排作证据。
  * 不做关系图。
* **出处**：Opus 按 2026-11-20 用户定的产品边界修正。

### V36Q-05 BlurFade 只借节奏

* **问题**：Magic UI 的 BlurFade 用 filter 模糊做进入效果。
* **做法**：基线机器没有显卡，frontend.md 第十一节也禁止用模糊做动效，所以只借它的依次进入节奏，仍用淡入加上浮。NumberTicker、AnimatedList 同样用 Vue 重写，不装包。
* **出处**：Opus 起草。
