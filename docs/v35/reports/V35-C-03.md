# V35-C-03 本地确定性检查

`bid/compliance.py` 核对工期与交货期上限、质保期与缺陷责任期下限，以及类似业绩一览表的签订日期、单项人民币金额与份数。期限按原单位比较，年可折算为月。类似业绩按项目名称去重，金额用 Decimal。含扫描识读、冲突承诺或无法确定的列值时保留人工核对口径，见 V35Q-15。

`bid/requirements.py`、`bid/schemas.py`、`api/bid.ts` 与 `BidRequirements.vue` 接通第 1 步参数预填、保存和回显。`bid/checks.py` 保留证据位置及重跑时的条目身份，适用的要求写入矩阵。`bid/conclusion.py` 将数值不符合项列入“需你核实”，`results.ts` 与 `export/bid_docx.py` 接入类别名称及报告留痕。
