# V35-C-02 标书检索

`bid/model.py` 按文件维护两级章节路径，正文与带章节正文的向量分数按 75% / 25% 混合。章节仅参与本机检索。首轮资格类要求保留一个最高分的同类证照短页片段，豁免 0.8 倍最高分截断，每格仍最多 3 个片段。重解析时由 `bid/pipeline.py` 清理该文件的向量缓存。实现口径记入 V35Q-14。
