# V35-C-01 图像凭证识字

## 改动

* `parsing/pdf.py`：文字页上没有矢量文字覆盖的独立大图只裁该区域 OCR（区域外涂白后找线框表格），产出 ocr_block / table_cell；计入 OCR 页数，提示沿用“图文混排，已对图片部分做 OCR”；标书延后识别同样处理。阈值见 V35Q-13。
* `parsing/docx.py` + 新 `parsing/docx_images.py`：正文内嵌图片按出现位置列出，证照尺寸的逐张 OCR，节点 `F{n}-IM{张}-B{块}` 紧跟在图片所在段落之后，`parent_loc` 为所在段落或单元格。文件审核与招标文件当场识别；标书投标文件排入已有的延后 OCR 队列（`bid/pipeline.py`）。`image.py` 抽出与图片文件共用的 `ocr_nodes`。
* 名额：图片区域页与 DOCX 图片只用剩余名额，超出提示不失败；已解析 DOCX 的占用按图片张数计。
* 导出：`export/docx_anchor.py` 比对节点时排除图片节点，批注 / 修订锚到图片所在段落。
