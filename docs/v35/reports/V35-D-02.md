| 稿次关系 | `task_files.prev_file_id`（迁移 0053，唯一、删除置空）；解析完按逐段相似度 ≥ 0.6、占新文件一半以上自动认稿；`PUT …/files/{fid}/draft` 改对照哪一稿或作为独立文件（防成环）；“传新一稿”上传带 `draft_of`，直接接在链的最新一稿后面；发起审核默认每条链只取最新一稿 | `review/drafts.py`、`assistant/service.py`、`review/service.py` |

| 对比视图 | 纸面分段开关第三项“对比上一稿”：新增浅底下划线、删除划线、整段删除单列“本稿已删除”、改过的段左侧竖线，未留痕为警示色竖线与小标，右缘光谱条标变化；右栏“变化 n”页签：摘要、全部 / 未留痕 / 新增 / 删除 / 修改、格式变化折叠、导出对照表，点一条纸面切到对比并定位 | `ConfirmCanvas.vue`、`DiffRail.vue`、`RunResult.vue` |
| 确认前就能看 | 确认页文件行“第 2 稿 · 对照《…》第 1 稿”（下拉改关系）、变化摘要与“查看对比” | `ConfirmWorkbench.vue`、`ReviewPane.vue` |
| 入口 | 结果页“传新一稿”；文件审核首页“最近的审核”每行“⋯ → 传新一稿”；跨会话文件名提示（结果页、确认页） | `RunResult.vue`、`Review.vue` |
| 导出 | 批注版勾选“同时标出与上一稿的变化（n 处，未留痕 m 处）”，每处一条“【对方改动 · 修改 · 未留痕】原文：…　本稿：…”，删除的挂后一段开头，文字一字不改；变化对照表四列“位置 ｜ 上一稿 ｜ 本稿 ｜ 是否留痕”，未留痕行加粗 | `export/diff_docx.py`、`export/annotated_docx.py` |

## 验收

* **样本**：`backend/tests/fixtures/drafts/`（`make_drafts.py` 生成，虚构）。二稿开修订改付款期限、违约金，关修订改争议解决地、删保密条款、插入质量保证一条（后面自动编号顺延）；三稿开修订改回付款期限、关修订改交货期限、一段只改标点。
* **对比质量**：一稿→二稿 5 处全部标出、类型正确：付款期限 30→60、违约金 0.5%→0.1% 为“已留痕”；争议解决地、删除保密条款、新增质量保证为“未留痕”；编号顺延不算变化。二稿→三稿：付款期限改回（已留痕）、交货期限 45→60（未留痕）、只改标点归入格式变化，不计未留痕。
* **效率**：300 段合同两稿（50 处变化）对比 37～40 毫秒（5 次）。
* **测试**：`tests/test_drafts.py` 4 项（三稿对齐与留痕、同段混合留痕与位置调整、文件名去稿次字样、会话认稿 / 对比 / 对照表 / 改关系 / 传新一稿 / 非本人 404）；相关的解析、会话、批注版、迁移、保留期测试共 189 项通过（`docx-2` → `docx-3` 改了 test_pipeline 三处断言）。
* **实走**（本机 compose + 模拟模型，账号 d02walk）：一稿审核 → 传二稿自动认稿 → 确认页第 1 稿自动取消勾选、第 2 稿成为主文件，摘要与“查看对比”正常 → 第 2 轮结果页“变化 5”、点条目纸面切对比并定位。批注版含变化 14 条批注（不含变化 9 条，多出 5 条“对方改动”），对照表四列、未留痕行加粗。浅色、深色 × 1440 截图交会话。
* **实走中修的两处**：结果页纸面默认打开已被取代的第 1 稿（改为被取代的稿排在最后）；纸面工具行多了第三个分段后文件页签被挤没（页签留最小宽度，回执条可收缩）。
* **构建**：`npm --prefix frontend run build` 通过。
