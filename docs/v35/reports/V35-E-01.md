# V35-E-01 定位收缩的删减

日期：2026-11-20　执行：Claude Opus 5.5　状态：**已完成**

## 做了什么

* **合同**：去掉修订版导出（`revised_docx.py`、`/runs/{id}/revised`、导出菜单与收尾条的入口）。批注版保留；建议条文本来就有“复制”按钮。
* **标书 · 条款清单**
  * 只抽 ★、否决、“必须 / 不得”类条款。“应当 / 需 / 请……提供”和编号注释的连带条目不再进清单；技术参数章节只收 ★ 与否决句（问题 7）。
  * 第五十一条默认行不再生成。“必须 / 不得”类条款落到新分组 `general`，检查方式为“只列出”。
  * 招标文件可以没有 ★ 和否决条款，确认清单时不再要求至少一条。
* **标书 · 关键参数**：整块撤下，最高限价、有效期、保证金、费率上限的比对随之去掉。报价方式改为按招标文件自动判断。代理机构是关键参数中的手填项，依赖它的“同一代理机构历史基线”一并去掉。
* **C-03、C-04 逐项**

| 检查 | 处理 |
|-|-|
| 工期、交货期、质保期、缺陷责任期、类似业绩 | ★ / 否决条款驱动：参数（`param_enc`）显示在条款上，可改，不满足为严重；其余条款不比对 |
| 费率 / 下浮率识别 | 保留，按招标文件自动判断 |
| 多个不同费率 | 保留，严重（法定否决） |
| 费率上限 / 下浮率下限 | 去掉（限价类） |
| 含税与不含税配套、税价换算 | 提示 |
| 修正后总价 | 去掉（属报价分析页） |
| 主辅机组成价复算 | 保留，提示 |

* **标书 · 结论**
  * 确凿 / 需核实 / 参考改为严重、提示两档。严重只收三类：
    * ★ / 否决条款不响应；
    * 本机能确定的法定否决情形：多个报价、证书过期、签章页标为缺章；
    * 串标强证据。
  * 低置信 OCR、引文未核实、模型的“响应待核实”降为提示，异常低价也是提示。
  * 唯一的人工操作是“不是问题”（`PUT /bid/{id}/dismissed`），可撤销，记在 `conclusion_enc.dismissed` 中。
  * 撤下的部分：Y/N 核实、评委签认、反馈记忆（含设置页那一节）、二次核验、“不适用”、要求响应矩阵、关系图、文件时间线、报价分析页、澄清通知书。
* **模型补查**：改为可选，本地检查后不再自动准备片段。只查 ★ 与否决条款中本机判断不了的，补查结果并入问题清单。
* **导出**：Word 改为问题清单，依次为严重问题（按投标人分节）、串标线索（并排对照）、提示和附录；去掉签字栏和结论性措辞。按投标人分节的版式留给 F-05。
* **数据**：迁移 0052 有以下变化。
  * 新增 `bid_requirements.param_enc`，`group` 增加 `general`。
  * 旧的“已排除”（条目、单元格、结论事项）并入 `dismissed`；“不适用”的要求改为停用。
  * 旧关键参数中工期类与业绩的取值写到对应 ★ / 否决条款上，其余只留报价方式。
  * 第五十一条默认行及其模型条目删除。
  * 删除 `bid_items` / `bid_cells` 的 `review_status`、`note_enc`，以及 `users.bid_feedback_enc`。
* **前端**：只删不改样式。结果页改为“问题清单｜各投标人｜串标线索”三个页签，新增 `BidIssues.vue`，沿用原骨架。删除 9 个组件。
