# V35-B-05 实体识别模型 INT8 选型评测

**结论：维持 FP32。** 动态 INT8 的万字识别耗时下降 43.2%。20 处原先以正确类别替换的标注出现退化，另有 3 处应提示内容在拟外发文本中露出。V35Q-03 的召回门槛未达到。

基于 `476a81e` 的虚构样本，本机 i5-13400、Docker 限 10 vCPU、每进程 8 线程，ONNX Runtime 1.31.0，断网 CPU 推理。以已登记的 `urchade/gliner_multi-v2.1` FP32 ONNX 为基线（Apache-2.0，分词文件 MIT）。用 ONNX 1.20.1 动态逐通道 QInt8 量化 81 个常量权重 `MatMul`；其他算子、分词、解码与阈值沿用现行版本。量化图漏计 `If` 分支引用的外层输入，按实际依赖调整 3 个节点的顺序后通过 ONNX 校验。

20 处类别退化包含 18 处机构和 2 处人名，均退为通用不确定项。8 段冻结留出文本的有效 logits 均为有限值，INT8 的最高置信度约 0.30，低于中置信门槛 0.40。补测仅收窄量化范围（`reduce_range=True`），冻结留出集仍为 0/48，在此结束筛查。

golden 实际输出为 `734 passed, 1 warning in 2.76s` 与 `11 failed, 723 passed, 1 warning in 3.78s`。INT8 候选 SHA-256 为 `fd7267e063d0628aa80bedaf2f9990e68d74544cca0e4fc8127259f3ad38b364`；按 ONNX 文件差额估算，模型层少约 216 MiB（未压缩）。结果取自本机，目标服务器未测。原始日志、量化脚本、候选及校验清单存于仓库外 `E:/aireview-eval/v35-b05/`。沿用 V35Q-03 的门槛。
