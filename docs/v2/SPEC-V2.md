## Z 部分：总验收与发布（V2-Z-00 填写，用户已确认 2026-10-29）

### 20.4 HTTPS（V2-Z，Z1；V2Q-160、V2Q-163）
原文：优先使用公司证书；没有时用 Caddy 内部 CA 签发，并通过组策略把根证书下发到员工电脑。可以先用服务器 IP 访问，之后再配置内网域名（如 review.公司域名）。
新文：系统用服务器的固定 IP 访问（静态地址或路由器地址保留）。证书由本系统自建的两级签发机构提供：根证书（10 年，名称约束只允许公司内网段的 IP、不允许任何域名）离线保管，私钥不放服务器；中间证书（10 年，名称约束只允许服务器 IP）放在 deploy/secrets/ca/，由 Caddy 签发并自动续期站点证书。用 `python -m app.cli gen-ca` 离线生成，换 IP 时只重新签发中间证书。员工电脑按当前用户导入一次根证书：http://<服务器IP>/cert/ 提供说明页、根证书与一键导入脚本（导入前校验指纹）；其余 http 请求跳转 https。根证书指纹与主密钥一并登记，由同一保管人离线保管根私钥。
理由：公司没有域、公司域名与可自管的 DNS，组策略与公开证书都不可用；原方案的根证书在数据卷中且未备份，根私钥泄露可冒充任何网站
