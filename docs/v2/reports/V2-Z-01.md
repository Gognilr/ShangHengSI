# V2-Z-01 HTTPS 根证书

2026-10-29，GPT-6.1 Sol。前置 V2-B-15 与 Z-00 已完成；依据已确认的 V2-Z 第一节和 V2Q-174 实施，不操作正式服务器，不修改电脑信任。

## 实现

- `site_ca.py` 与 CLI `gen-ca`：ECDSA P-256，根 pathLen=1、中间 pathLen=0，关键名称约束为指定私网 / 服务器 IP 和 invalid 域名；10 年期限，私钥 600，不覆盖。换 IP 沿用根证书，新中间期限不超过根剩余期限。
- Caddy 2.11.7 直接加载根公证书与中间证书、私钥，使用自定义 `site` CA，不需根私钥，不安装容器信任。外部提供的中间证书由 Caddy 原生机制保留，不自动换发。启动脚本区分开发 / 自定义配置，部分文件缺失或发现 root.key 时拒绝启动。
- HTTP `/cert/` 提供说明、DER SHA-256 核对步骤和根公证书；其余 HTTP 请求跳转 HTTPS。下载只匹配根公证书，不开放 CA 目录。
- install 检查 CA 文件及根私钥缺席，从 root.sha256 生成下载页；release 显式复制六个模板 / 片段，不复制证书、私钥、生成的页面。restore 只追加保管提示，upgrade.sh 按 V2Q-174 未改。
- 运维说明仅更新第 5、8、10、11 节，列出离线保管、两种员工导入方式、换 IP、到期更换与恢复步骤。
