- 中英标签识别使用 `parties.bilingual_label_text`：仅在含中英文字和冒号的节点内，将已知成对标签的英文部分遮盖成等长空白供识别，原文和字符偏移不变。共用于 parties、格式化编号、人名、地址和 NER 残余文本，避免英文标签被当作值。签约方标签按现有同角色中文 / 英文组合生成；其余类别按已支持的标签成对识别。

- 无冒号 Account / A/C / Acct 数字账号使用原 ACCOUNT 数值键，8～30 位数字；新增 ИНН / КПП / ОГРН / UEN / ABN / EIN / CNPJ 为 IDNO。原账号、证件号优先级保持。
