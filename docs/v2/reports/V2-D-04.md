## 实现

- assistant/templates.py 与 resources/prompts/assistant_templates.md：五个模板参数白名单、文件个数/归属/重复检查、九种目标语言、摘要侧重点、回复语气与语言选项；无正文时生成固定中文消息。模板说明原段拼入 system；参数选项进入脱敏上下文。回复只提取独立 `---` 之后的草稿。
- assistant/translate.py、prompt.py、job.py：默认按 4000 字完整节点分段，超长节点独立成段，不带历史消息；发送前和 worker 启动时按较小的月度/每日剩余量预检段数。每段经流式网关，累计 token 和 segments_done；第二段失败仍保留第一段。位置编号异常时整段放在第一个节点并标记 unaligned。按目标书写系统选择对照表已有名称写法，还原仅在本人查看时进行，并返回固定核对提示。
- assistant/compare.py、job.py、gateway.py：模型仅对齐价格代号，强制非流式 JSON，关闭自动重试。规范化结果只含代号和位置；字面数字、错误类别和未知代号不参与计算。查看时在内存中还原，以 Decimal 计算同币种最低价、1 位差额百分比和完整合计。无效 JSON 以 BAD_RESPONSE 收尾，并保留已发生的 token 用量。非流式 assist 继续执行上限、出口复检与外发记录。
- assistant/service.py：模板参数/固定消息与重试预检接入，返回翻译对照、按语言还原、现场比价结果和草稿；计算数值转换为十进制字符串，不写回消息和外发记录。
- admin/settings_store.py：只登记 assistant.translate_segment_chars 默认 4000。
