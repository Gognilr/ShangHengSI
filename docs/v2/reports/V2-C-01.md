# V2-C-01 分类并发与连接池

日期：2026-10-25。执行：GPT-6.1 Sol；批次独立审核仍由 V2-C-09（Opus）执行。

## 实现与范围

- `jobs.claim(db, worker_id, types)` 在原有 queued、到期、按 id、FOR UPDATE SKIP LOCKED 查询中增加类型过滤；空类型不取任务。
- worker 审核组只取 review，解析组只取 parse，维护组固定一条只取 backup、retention。默认 8 / 2 / 1，保留 OCR 全局互斥锁及三组共用的 30 秒退出期限。
- 两个新并发变量只接受 1～32 的整数；旧 WORKER_CONCURRENCY 不再读取，设置时每次启动只警告一次，日志不输出旧值。
- worker 独立 sessionmaker 使用 pool_size=max_overflow=审核+解析+2；app 默认引擎选项不变。网关外发记录独立会话沿用调用方 bind，使用 worker 的连接池。
- `.env.example` 与 compose 改用两个新变量，新变量仅加在 worker。V2Q-60 已由用户批准：共用环境块移除旧变量，三个既有测试文件只同步配置断言或 claim 参数。
- 未连接正式服务器、未调用真实模型、未下载文件；保留两份既有未跟踪界面方案。
