# V2-C-06 设置权限拆分与以后自动替换

2026-10-26，GPT-6.1 Sol。按 design/V2-C.md 第六节与已确认 V2Q-68 执行，前置 C-05 已完成。开工基线 10528b0。

## 改动

- users.role 与迁移 0016 增加 sys_admin、biz_admin；旧 admin 保持两者兼任，降级把两种新管理员转换为 admin。账号管理保持按 id 顺序锁定系统管理员行，保底条件改为至少一个启用的 sys_admin/admin；禁止修改自身角色、停用自身的规则保留。CLI create-admin 本来就创建 admin，符合兼任角色约定，无须改值。
- 账号、模型、用量与数据接口使用 require_sys_admin；审核要求、脱敏设置与词条接口使用 require_biz_admin。拒绝仍为 403 FORBIDDEN，任务/轮次/问题/对话依然按 owner 隔离，任一管理员访问他人对象均为 404。旧 require_admin 保留供兼容测试引用，实际设置路由已全部改用两种新依赖。
- /auth/me 返回四角色；备份、磁盘、调用上限、保留设置提醒给系统管理员，词条冲突提醒给两类管理员；普通用户无提醒。前端顶栏、分页导航、直接访问守卫和角色下拉同步四角色。无权限分页跳到首个允许分页。
- 提醒以 code/message 组合键记录到 Pinia 内存集合，“本次收起”后过滤显示；同次登录站内切换保留，刷新、清空状态、退出和重新登录恢复；文字变化生成新键；全收起后不渲染提醒容器。没有持久化存储。
- 手动补充和疑似遗漏的 CUSTOM 类别增加可选“以后自动替换”，默认不勾选。后端保存当前替换时同事务加密写入 custom 词条、记录当前用户，不等确认发送；固定提示词冲突全部回滚。kind/term_hash 唯一键并发去重，已有停用词条不由普通用户重新启用；细节登记 V2Q-69（待确认）。
