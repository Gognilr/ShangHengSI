### 3.1 外发构建

* `quotes.QuoteTable` 增加 `detailed: bool`：数据行数 ≤ `DETAIL_MAX_ROWS = 200` 时为 True。
* **detailed 的表**：在表头行第一个单元格的位置先输出一行表级说明 `[{表格位置}] 【报价明细表：共 N 行，币种 …，本地校验：…；明细逐格列在下方】`（不再列产品，产品已在明细中），然后照常输出该表全部单元格（与普通表格相同，每格一行）。
* **超过 200 行的表**：沿用现在的整表汇总（含产品），单元格不发送。
* `summary_text(t, note)` 按 `t.detailed` 生成两种文字；`validate.load_node_views` 用同一函数，保证模型引用表格位置时按实际发送的文字校验（Q-72 ⑥ 的映射不变）。

### 3.2 金额为 0 不替换

`detect.find_amounts` 与 `detect.find_bare_amounts` 中数值为 0 的命中（`0`、`0.00`、`¥0`、`USD 0.00` 等）不返回。理由：0 不泄露任何信息，替换后模型看不出零价、赠送行。出口复检的重扫调用同一函数，因此自然不拦截 0 值；对照表中不会出现 0。

### 3.3 明细行金额不加比例

engine `_ratio_inserts` 跳过位于任何报价明细表单元格（`row_locs`）中的金额：每一项都附“占合同总价的百分比”等于把整份报价的价格结构交给模型。正文中的分期金额照旧加比例。判断范围用 `quotes.find_quote_tables` 的 `row_locs`（与是否 detailed 无关）。

### 3.4 覆盖说明

`coverage.quote_tables` 只记 detailed 为 False 的表，说明文字改为“{文件} {位置} 报价明细表共 N 行，超过 200 行，只把汇总信息发给 AI，行级数据未逐行审核”。detailed 的表不再出现在覆盖说明中。

### 5.1 L-09 分期金额

**(a) 比例与金额**：同一节点内匹配“{基数}的 N%，即 / 计 / 为 / 合（人民币 / RMB / ¥）X（元 / 万元）”，允许填空括号（Q-134 ①）。

* 基数为“合同总价、合同总额、合同金额、合同价款、总价款、总价”时，取 `consistency.contract_amount` 的合同总价；其他基数（如“软件总价款”）只有当同一文件中恰好有一处“{基数}（为 / 是 / ：）{带币种或“元”的金额}”时才用它，否则不校验。
* 期望金额 = 基数 × N% 四舍五入到 2 位；X 为“万元”时乘 10000；币种不同不校验。差额 > 0.01 时报 L-09，严重程度**高**，详细说明“{位置}：{基数}的 N% 应为 {期望}，文中写 {X}”，`ai_summary`“{位置}：比例金额与基数不一致”。

**(b) 各期比例之和**：在同一个一级条款内（从标题或正文含“付款、支付、结算”的一级条款节点起，到下一个一级条款为止），收集形如“（合同总价 / 合同总额 / 合同金额 / 合同价款 / 总价款）的 N%”的比例，至少 2 个时求和：

* 合计 > 100%：报 L-09，**中**，“各期付款比例合计 N%，超过 100%”。
* 合计 < 100%：报 L-09，**低**，“各期付款比例合计 N%，不足 100%，请确认其余部分是否另有约定（如质保金在其他条款）”。
* 等于 100%（差 ≤ 0.01）不报。

L-09 的严重程度按上面逐条给，不用 `SEVERITY` 的固定值（`SEVERITY["L-09"]` 设为 high 仅作默认）。

### 5.3 L-11 增值税税率

## 六、小修三项（V2-A-06）

**文件范围**：`backend/app/redaction/outbound.py`（`party_description`）、`backend/app/redaction/restore.py`、`backend/app/review/service.py`（`locations`）、对应测试。

### 6.1 主体说明不写“未知”

`party_description` 中国家为空或“国家未知”、类型为空或“类型未知”时不写这一项；一项都没有时只写代号（如“客户_A”）。第二步界面仍显示“国家未知 / 类型未知”（不改前端）。

### 6.2 还原兼容括号不一致

方括号代号（`[` 开头、`]` 结尾）的还原写法扩展为：开括号 `[`、`［`、`【` 任一，闭括号 `]`、`］`、`】` 任一，共 9 种组合。其他规则不变（长代号优先、一次扫描、`#` 键不还原）。

### 6.3 位置显示补一级条款

`ResultView.locations` 中，节点的 clause\_no 为子项编号时（`1.`、`2)`、`（3）`、`a.`、`(b)`、`（一）` 这类：纯数字或单个字母、可带括号或句点、顿号），向前查找同一文件中最近的、clause\_no 形如“第…条”或“第…章”的节点，显示为“{文件名} 第五条 2.”。找不到时保持现状。
