## 一、外部审计文档的核对结论（V2-U-00）

两份文档的主要判断正确：问题不在配色，在视觉层次和排版数值。下列各项已在代码或截图中核实：

| 项 | 核实结果 |
|-|-|
| 结果页首屏 | 1366×768 下，信息卡（6 项元信息）+ 等级计数 + 覆盖说明占满首屏，问题清单的标签页被底部操作栏压住，**一张问题卡片也看不到**（V2-C-08 截图 result-1366.png） |
| 两个滚动条 | 结果页整页滚动 + 右栏内部滚动，窗口右侧并排两条滚动条 |
| 同一筛选两个入口 | 等级计数块与“全部等级”下拉都绑定 `fSeverity` |
| 字体设置两份 | `App.vue:16` 与 `theme.css:53` 各一份，前者含 Arial |
| 字重 | 600 共 26 处、700 一处、500 没有 |
| 数字 | `font-variant-numeric` 全站 0 处，表格中的日期、金额、编号不等宽 |
| 原文段距 | `margin-bottom: 8px` 配行高 1.7（23.8px），段与段分不开 |
| 焦点外环 | `--el-color-primary-light-5` 对白底约 2.8:1，低于 3:1 |
| 步骤条 | 连接线 `left:-18%; width:36%`，宽度变化时两端悬空 |
| 规范自相矛盾 | 间距白名单没有 28px，面板内边距却要求 28px；统计块圆角 10px、数字 22px 不在白名单 |

**修正或不采纳的建议**（V2Q-107）：

| 建议 | 处理 | 理由 |
|-|-|-|
| 补 500 字重，表头和标签用 500 | 不采纳；只用 400 / 600 两档，层次靠字号和颜色 | 公司电脑是 Windows，实际显示的微软雅黑只有常规、粗体（另有细体），500 显示成 400、600 显示成粗体。要真正的三档只能自托管字体（V2Q-102） |
| 正文 `white-space: pre-wrap` 改为 `normal` | 不采纳，保留 `pre-wrap` | 合同里常见“甲方：______    ”这类连续空格和段内换行，`normal` 会吞掉；frontend.md 第九节也要求原文按纯文本保留空白 |
| 阅读区限宽 34em（文档称约 36 字） | 改为 40em | 中文 1em 就是 1 个字，34em 只有 34 字；右栏本身只有半屏，40 字左右更合适 |
| 段距 16px | 改为 12px | 合同的“款”多为一两行的短段落，16px（约 0.6 倍行高）会使条款显得松散 |
| 条款号独立成列（grid 34px） | 不采纳；只给自动编号加悬挂缩进 | 大部分合同的编号写在正文里（“第1条 ……”），`docx__no` 只在自动编号时出现，固定一列会让多数段落左侧空出一条 |
| 全站 `tabular-nums` | 只用于表格、分页、统计数字、时间、条款号、表格单元格 | 正文中的数字用比例宽度更好看；需要纵向对齐的地方才用等宽 |
| 加面包屑 | 不采纳；结果页工具条加“← 审核历史” | 只有两个菜单，面包屑多余 |
| 首屏加“建议改付款条款后再签”一句话结论 | 只做计数（“共 N 处问题”+ 三档计数） | 前端不生成审核判断；结论只来自模型输出和本地校验 |
| 审核中页显示“预计还需 40 秒” | 不显示 | 没有可靠的数据估算，只显示已用时间与分段进度 |
| D12“el-table 95 处，表格滥用” | 不成立 | 统计时把 `el-table-column` 也算进去了；实际只有 18 个表格 |
| 骨架屏 | 有限采纳（V2-U-02，V2Q-105） | frontend.md 原来禁用；主流产品在列表、结果首次加载时用骨架屏，只开放这两处 |
| `text-autospace`（文档称 Chrome 117 起支持） | 采纳，全局开启 | 实际是 Chrome 140 起支持；旧浏览器忽略，没有副作用 |
| 代码片段中的颜色值（#8A94A6、#D3D8DE 等） | 改为令牌 | 十六进制颜色只能写在 theme.css |

## 二、设计令牌与全局排版（V2-U-01，测试先行）

### 2.1 字号—行高—字重（成对使用，不单独取值）

| 令牌 | 字号 / 行高 / 字重 | 用途 |
|-|-|-|
| `--si-font-display` | 32px / 1.3 / 600 | 登录页品牌主张 |
| `--si-font-title-lg` | 30px / 1.3 / 600 | 登录页“欢迎登录” |
| `--si-font-title` | 24px / 1.35 / 600 | 页面标题（设置五页的 PageHeader） |
| `--si-font-h2` | 18px / 1.45 / 600 | 面板标题、结果页文件名、对话框与抽屉标题 |
| `--si-font-h3` | 16px / 1.5 / 600 | 问题卡片标题、选项卡片标题、审核中页标题 |
| `--si-font-h4` | 15px / 1.5 / 600 | 面板内分组标题 |
| `--si-font-reading` | 15px / 1.8 / 400 | 原文阅读区正文 |
| `--si-font-body` | 14px / 1.6 / 400 | 界面正文、表单、表格内容 |
| `--si-font-meta` | 13px / 1.5 / 400 | 元信息、标签列、表头、面板标题旁说明 |
| `--si-font-caption` | 12px / 1.6 / 400 | `.hint`、固定声明、图例 |
| `--si-font-stat` | 24px / 1.3 / 600 | 统计块数字（原 22px） |
