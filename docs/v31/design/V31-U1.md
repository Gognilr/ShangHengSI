## 一、设计令牌（V31-U1-01，Opus，high）

### 1.1 外壳与纸面

* `<html>` 上两个属性：`data-shell="night|light"`（外壳）、`data-fx="full|lite|off"`（解析后的特效级别，3.3）。默认 `night`。
* **外壳**指导航、页面底、面板、表单、表格、弹层等全部界面；**纸面**指显示文件正文的区域，任何外壳下都是白纸黑字。
* 纸面用类 `.si-paper`：在该元素上重新声明浅色的全部令牌，其中的 Element Plus 组件、标签、高亮自动按浅色显示；纸面外围的底色区用 `.si-stage`。挂到弹层（tooltip、下拉）的内容不在纸面内，按外壳显示。
* theme.css 分三块，顺序固定：

```css
/* A 浅色外壳与纸面的取值 */
:root, .si-paper { --si-bg-canvas: …; --si-ink-1: …; … }
/* B 夜幕外壳的取值（只覆盖 A 中随外壳变化的令牌） */
html[data-shell="night"] { color-scheme: dark; --si-bg-canvas: …; … }
/* C 映射与派生：Element Plus 变量、旧令牌、color-mix 派生色，全部引用 A/B 的令牌 */
:root, .si-paper { --el-bg-color: var(--si-surface-1); --el-color-primary-light-9: color-mix(in srgb, var(--si-blue) 10%, var(--si-surface-1)); … }
.si-paper { color-scheme: light; background: var(--si-paper); color: var(--si-paper-ink); }
```

  自定义属性在声明它的元素上取值后再向下继承，所以 C 块必须同时写在 `:root` 与 `.si-paper` 上，纸面内的派生色才会按浅色重算。

### 1.5 圆角、阴影、控件尺寸、间距

* **圆角六级**：纸面与行内高亮 4px（`--si-radius-paper`）；标签与胶囊 6px（`--si-radius-tag`）；按钮、输入框、下拉框、分段 8px（`--el-border-radius-base`）；面板、卡片、上传区 12px（`--si-radius-card`）；弹层、对话框、抽屉、提示 16px（`--si-radius-pop`）；登录卡片与外发确认卡 20px（`--si-radius-sheet`）；圆形 50%，灵动岛与开关为全圆角。
* **阴影三级**：`--si-shadow-1`（浮起）、`--si-shadow-2`（悬停卡片、粘底栏）、`--si-shadow-3`（弹层）。夜幕：`0 1px 2px rgba(0,0,0,.4)`、`0 8px 24px rgba(0,0,0,.35)`、`0 24px 60px rgba(0,0,0,.5)`；浅色：`0 1px 2px rgba(16,24,40,.06)`、`0 8px 24px rgba(16,24,40,.08)`、`0 24px 60px rgba(16,24,40,.16)`。`--si-paper-shadow` 两外壳都是 `0 0 0 1px rgba(0,0,0,.08), 0 12px 40px rgba(0,0,0,.18)`（夜幕再加深为 `.35`）。
* **光效**（只在完整特效）：`--si-glow-blue` 主按钮与选中菜单的蓝色辉光；`--si-blur: blur(20px) saturate(140%)` 弹层毛玻璃。精简与关闭时两者为 `none`，弹层改为不透明的 `--si-surface-pop`。
* **控件尺寸（1366×768 基准，32）**：默认 36px（原 40px），表格内小控件 28px，登录页 44px。
* **页面节奏**：`.page` 内边距改为 24px 32px 40px；`.panel` 内边距 20px 24px；间距档位不变（4～48px）。
* **验收视口**：1366×768 屏幕上 Edge 标签页最大化后的可视区约 **1366×640**，安装为应用后约 1366×705。U1 只要求现有页面在 1366×640 下无横向滚动、无遮挡；首页、确认页、结果页的“一屏可完成”要求在 U2、U3 按此视口验收。`body` 最小宽度 1280px 不变（SPEC 21）。

### 1.6 风险标签与状态

风险等级不再用实心深色标签（夜幕下白字对比度不足），统一为**色点 + 文字的浅底胶囊**：底 `color-mix(in srgb, 状态色 16%, var(--si-surface-1))`，文字 `--si-*-ink`，左侧 6px 圆点为状态色，`--si-font-label-sm`、`--si-radius-tag`、高 22px。高 = `danger`，中 = `warn`，低 = `info`；问题卡片左侧色条、等级计数的圆点、文档光谱条用同一状态色。**低风险不用绿色**（不变）。

Element Plus 标签三种 `effect` 统一换为：`light` = 上述浅底胶囊（无圆点）；`dark` = 浅底胶囊加圆点（现有页面的等级标签用的就是 `dark`，U1 不改页面即生效）；`plain` = 透明底 + 1px 状态色 40% 边框 + 状态色文字。`labels.ts` 中的枚举与颜色对应关系不变。

## 二、字体（V31-U1-01）

### 2.1 许可证核实（V31Q-03 → V31Q-11）

* **MiSans 不满足**：《MiSans 字体知识产权许可协议》为可撤销许可，不得对字体或其组件改编或二次开发，不得单独出租、转授、赠与、出借、再分发字体文件；软件内嵌须注明。按需分片属于修改字体文件，仓库公开在 GitHub 上、发布包附带字体文件属于再分发，均有违约风险。
* **改用思源黑体**（V31Q-03 的备选）：取 Google Fonts 发行的 Noto Sans SC 可变字体（与思源黑体同一设计；SIL OFL 1.1，版权行 “Copyright 2014-2021 Adobe … with Reserved Font Name 'Source'”）。OFL 允许分片、随软件分发、商用；保留名称为 “Source”，分片后的字体族名用 `SI Sans`，不使用 “Source” 字样，满足 OFL 对修改版本的要求。
* **JetBrains Mono**：SIL OFL 1.1，版权行 “Copyright 2020 The JetBrains Mono Project Authors”，无保留名称；族名用 `SI Mono`。
* 两份 OFL 全文随字体放入仓库并随前端发布（`/licenses/`）。OFL 不要求在界面署名，不加署名。

### 2.2 文件与分片

* 来源（下载前经用户确认，V31Q-06 的做法）：google/fonts 仓库 `ofl/notosanssc/NotoSansSC[wght].ttf` 与 `OFL.txt`；JetBrains/JetBrainsMono 发布包中的 `fonts/variable/JetBrainsMono[wght].ttf` 与 `OFL.txt`。都固定到具体提交或版本号，SHA-256 记在 `frontend/src/assets/fonts/SOURCES.md`。原始 TTF 不进仓库。
* 脚本 `frontend/scripts/build_fonts.py`（只用 fonttools；在 `python:3.12-slim` 一次性容器中 `pip install fonttools==… brotli==…` 后运行，命令写在脚本头部注释）：
  1. 两款字体的字重轴都裁到 400～600（`fontTools.varLib.instancer`）。
  2. SI Sans 按 Google Fonts 对 Noto Sans SC 的分片范围切成约 100 片 WOFF2：该范围按字频排好，常用页面只需加载少数几片。范围从 Google Fonts 的 CSS 中取一次，存为 `frontend/scripts/sans_slices.json` 进仓库，之后不再联网。
  3. SI Mono 只保留 Basic Latin、Latin-1、常用标点与箭头，一个文件。
  4. 生成 `frontend/src/styles/fonts.css`：每片一条 `@font-face`（`font-family`、`font-weight: 400 600`、`font-display: swap`、`unicode-range`、`src: url(../assets/fonts/…woff2) format("woff2")`）。
* 产物进仓库：`frontend/src/assets/fonts/*.woff2`（预计合计 6～9 MB）、`fonts.css`、`SOURCES.md`；`frontend/public/licenses/OFL-SI-Sans.txt`、`OFL-SI-Mono.txt`。
* `main.ts` 的样式引入顺序改为：Element Plus → `fonts.css` → `theme.css` → `skin.css` → `common.css` → `motion.css`。

### 2.3 加载

Vite 把字体文件打成带哈希的 `/assets/…woff2`，浏览器按页面实际用到的字只下载对应分片；首次访问常用页面约 1～2 MB，之后走缓存。`index.html` 预加载 SI Mono 一个文件与 SI Sans 的拉丁及符号分片（`<link rel="preload" as="font" crossorigin>`，由构建脚本给出文件名；做不到稳定文件名时不预加载）。

### 2.4 缓存头（Caddyfile 一行）

前端静态文件的 `handle` 中加 `header /assets/* Cache-Control "public, max-age=31536000, immutable"`：`/assets/` 下全是带哈希的构建产物，可以长期缓存；`index.html` 不加。

## 三、动效与外观（V31-U1-01）

### 3.1 三层

| 层 | 时长 | 缓动 | 动什么 | 例 |
|-|-|-|-|-|
| 微交互 | 120～200ms（`--si-dur-1: 160ms`） | `--si-ease`（`cubic-bezier(.2,.8,.2,1)`） | 颜色、底色、透明度；按下 `scale(.97)` | 按钮、开关、悬停、选项卡 |
| 结构过渡 | 240～450ms（`--si-dur-2: 320ms`，离开 `--si-dur-exit: 200ms`） | 进入 `--si-spring`（`linear()` 弹簧，概念稿取值），离开 `--si-ease` | 位移与透明度 | 页面进入、抽屉、弹层、列表增删、定位原文、分段滑块、灵动岛变形 |
| 品牌时刻 | 0.8～2.5s，可循环 | 自定 | 位移、透明度、旋转（`@property` 角度） | 登录开场、本地扫描、AI 视野切换、审核中仪式、AI 生成中（在 U2～U4 实现） |

### 3.2 规则

1. 循环动画只在系统等待期间出现（解析中、审核中、生成中），等待结束即停；页面隐藏（`document.hidden`）时暂停。
2. 结构过渡与品牌时刻只动 `transform`、`opacity`；不动画 `width`、`height`、`top/left`、`box-shadow`、`filter`。例外只有三处，都是单个小元素：灵动岛宽度、分段控件选中块的宽度、开关的底色。
3. **动画从不推迟结果出现**：结果就绪即可操作，仪式是叠加层，就绪时 200ms 内淡出；路由切换只有进入动画（`si-page`：透明度 0→1 + 上移 6px，240ms），旧页面立即移除，不用 `mode="out-in"`。
4. 每个品牌时刻在精简特效下有静态替代（定格的最终画面 + 文字进度），在关闭特效下只有文字与已用时间；进度信息在三个级别中完全相同，动效只是表现。
5. 动效令牌与通用过渡写在 `styles/motion.css`：时长与缓动令牌、`si-fade`、`si-rise`（上移 8px 淡入）、`si-pop`（`scale(.96)` 淡入）、`si-list`（含 `-move`）、`si-page` 五组 Vue 过渡类。Element Plus 的 `--el-transition-duration` / `-fast` 指向 `--si-dur-2` / `--si-dur-1`。
6. `html[data-fx="off"]`：全部 `transition`、`animation` 关闭（同现有 `prefers-reduced-motion` 规则，改为按 `data-fx` 判断）；`html[data-fx="lite"]`：`--si-blur`、`--si-glow-blue`、`--si-ambient` 为 `none`，品牌时刻用静态替代，微交互与结构过渡保留。

### 3.3 外观设置与自动降级（43）

* **入口**：侧栏用户菜单“修改密码”之上加“外观”，打开 `AppearanceDialog`（第五节）：外壳“夜幕 / 浅色”，特效“自动 / 完整 / 精简 / 关闭”，下方一行说明自动档当前结果与原因。修改立即生效，不进入未保存状态。登录页不放入口，按已保存的设置显示。
* **存储**：`localStorage` 键 `si.appearance`，值 `{"shell":"night","fx":"auto"}`；只存本浏览器，不发送到服务器（PLAN 第四节第 5 条）。读写包在 try/catch，读不到按默认（夜幕、自动）。
* **首屏不闪**：`index.html` 的 `<head>` 内联一小段脚本，在样式生效前读出设置并写 `data-shell`，按 `prefers-reduced-motion` 先写一个 `data-fx`。
* **状态**：`stores/appearance.ts`（Pinia）持有 `shell`、`fxChoice`、`fxResolved`、`fxReason`，负责写 `<html>` 属性与存储；`utils/motion.ts` 提供 `useFx()`、`motionMs(layer)`、`useLoop(active)`（返回“此刻是否播放循环”：等待中、特效为完整、页面可见）、`watchFrames()`（3.4）。
* **自动档**按顺序判定，命中即停：

| 条件 | 结果 | 对话框中的原因 |
|-|-|-|
| 系统设置了减少动态效果 | 关闭 | 系统设置了减少动态效果 |
| WebGL 以 `failIfMajorPerformanceCaveat: true` 取不到上下文，或渲染器名含 SwiftShader、llvmpipe、Microsoft Basic Render、WARP | 精简 | 检测到软件渲染（远程桌面或无显卡） |
| `navigator.hardwareConcurrency ≤ 2` | 精简 | 处理器核心较少 |
| 运行中掉帧（`watchFrames`：品牌时刻开始后 1.5 秒内平均帧间隔 > 34ms） | 本次打开期间降为精简，不写存储 | 运行中出现明显掉帧 |
| 以上都不是 | 完整 | — |

  用户手动选择的级别优先于以上全部（V3Q-28）。WebGL 检测只做一次，取完即释放上下文。

### 3.4 性能预算（44）

| 项 | 预算 |
