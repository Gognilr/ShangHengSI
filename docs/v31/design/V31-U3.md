### 0.4 共用约定：“未能还原”的标出（V31-R、V31-P，U3 做好、U4 复用）

接口给出的标记 `{start, end, kind}`（码点下标）由 `MarkedText` 渲染为：原文字不变，加 `--si-warn-ink` 色 1px 虚线下划线与浅警告底，悬停 / 聚焦时提示下表文字。整段有标记时，所在卡片或消息底部一行次要警告色“有 N 处未能还原，已原样标出”。

| kind | 提示 |
|-|-|
| variant | 代号写法有变化，无法确定指哪个对象，未还原 |
| unknown | 模型提到了文件中没有的对象 |
| shared | 共用代号，此处可能对应多个值，未还原 |
| note | 系统标记，不是合同文字 |
| date | 模型写的日期，未能对应到原文日期，请核对 |
| literal | 模型自己写的账号、金额等，不是来自文件，请核对 |
| calc | 算式未能在本机计算 |

### 1.2 标记与计算的小工具（`utils/marks.ts`）

* `splitMarks(text, marks)`：按码点切分为 `{ text, kind? }[]`（与 `utils/compare.ts` 的码点处理一致；越界或重叠的标记丢弃后面的）。
* `markTokens(text, marks)`：返回各标记对应的原样文字集合（U4 的 Markdown 回复用，按文字匹配标出）。
* `calcLines(text, calcs)`：按 `line_start / line_end` 把回复切为 `{ text } | { calc }` 段，供 `CalcResult` 就地替换算式行。

### 1.3 文字（`utils/labels.ts`）

* `MARK_KIND`：0.4 的提示表。
* `LOCAL_CHECK`：加 L-13 报表勾稽、L-14 分级合计、L-15 公式重算、L-16 疑似手填、L-17 收款账号不一致、L-18 签约方名称不一致、L-19 编号单价数量不一致、L-20 隐藏文字、L-21 疑似写给 AI 的指令（与 SPEC 10.2 同名）。

### 1.5 “另存为”（29，V31Q-82）

`utils/save.ts` 的 `saveBlob(blob, filename)` 改为三级，调用方式不变：

1. 有已授权的工作文件夹：写入该文件夹（现状，SPEC 6.9）。
2. 否则浏览器支持 `showSaveFilePicker` 且 `navigator.userActivation?.isActive` 为真（点击导出或确认导出的按钮后仍在有效期内）：打开系统“另存为”对话框，建议文件名为 `filename`，类型按扩展名（docx / xlsx）；保存成功提示“已保存：{文件名}”并返回 true；用户取消时提示“已取消保存”并返回 true（不再下载）。
3. 其余（不支持、激活已过期、写入失败）：普通下载（现状）。

导出耗时较长导致激活过期时退回普通下载，不另弹提示框；Edge 的下载设置若为“每次询问保存位置”也会弹出另存为。助手导出、审核历史导出共用此函数，自动受益。

## 十、风险

| 风险 | 应对 |
|-|-|
| 原文与问题栏左右对调后，老用户找不到问题 | V3.1 发布前无人使用（V31Q-08）；问题栏顶部结论块与分区标题足够醒目 |
| 只读画布替换 `DocPreview` 节点渲染后，Word 表格、页眉页脚的显示与旧版不同 | 画布已在确认页按同一份节点排版并验收（U2）；PDF 与图片仍可切到“原件” |
| `quote_excerpt` 为空或在节点中出现多次时标注不准 | 只在恰好出现一次时标片段，否则整段竖条；定位精度仍为段落级（SPEC 6.3） |
| 光谱条按节点序号而非像素，长表格处位置偏差 | 只作概览与跳转；点击后以节点定位为准 |
| “另存为”激活过期退回普通下载，行为不一致 | 只影响生成很慢的导出；工作文件夹仍是首选，说明写入 SPEC 6.9 |
| 仪式在弱电脑上掉帧 | 自动降级（`watchFrames`）；元素 ≤ 30、只动 transform / opacity；关闭特效只有文字 |
| 回执数字与实际不符 | 只显示后端 receipt；旧轮次不显示；实际发送文字可随时查看 |
