2. **分工**：界面批次（V31-U1～U4）由 Opus 写设计、做全局基础并审核，Sonnet 5.5 连续实现页面任务；其余批次由 GPT-6.1 Sol 连续实现，Opus 细化与审核。

4. **测试**：沿用 V3 第 2 条。改了脱敏、外发构建或还原的任务另跑 `tests/test_redaction_golden.py`、`tests/test_a03_outbound.py` 与回程样本测试；界面任务只跑 `npm --prefix frontend run build`，浏览器检查（1366×768、1440×900、1920×1080，夜幕与浅色外壳，完整与精简特效）在批末集中做一次。
5. **性能实测**：界面批的集中测试另在本机用 Edge 性能面板记录首页、确认页、审核中三处的帧率；V31-Z 在公司最低配置电脑与远程桌面下实测（PLAN 第三节第 5 条）。
6. **真实模型**：只在 V31-R-01 与 V31-E 的评测任务中、经用户同意、用虚构样本调用；报告只写数字。
