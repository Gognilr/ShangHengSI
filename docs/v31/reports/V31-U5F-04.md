# V31-U5F-04 智能助手输入框与文件、全站粘贴文件

2026-11-06 · Opus 5.5（用户指定在本会话执行，原定 Sonnet）· 设计见 [V31-U5F.md](../design/V31-U5F.md) 第四节。

## 改了什么

* **9A 首页布局**：只加了文件、还没发出第一条消息时，页面保持首页布局（标题与输入框居中，文件标签在框内，模板仍可选）；发出第一条消息后转为对话布局，对话区淡入上移。输入框是同一个组件实例，切换时不丢输入。
* **9B 已确认的文件可以移除**：后端去掉 `FILE_CONFIRMED` 限制。移除后后续提问不再使用该文件；已有问答与对照表保留（会话对照表按固定代号累积，历史回复仍能还原）。移除确认框区分已确认 / 未确认的说明。
* **9C 文件状态**：标签按文件显示“正在上传 n%”→“本机解析中”（转动）→“待确认 / 已确认”；解析失败、转写失败在框内列出原因，转写可“重试”，解析失败可“移除”。解析与识别在服务器上是同一步，没有分阶段进度，所以不单列“识别中”。
* **9D 输入框**：首页布局与对话中同宽；对话中默认 1 行、随输入增高，首页 3 行。
* **9E 返回**：智能助手、会议纪要、翻译的全屏确认脱敏 / 校对逐字稿弹窗顶栏改为“← 返回对话 / 会议纪要 / 翻译”按钮（Esc 同效）。确认页的处理逐项保存在服务器，返回后再进不丢。
* **10 文件框**：去掉“本次提问使用哪些文件”下拉框。已确认的文件标签本身可点选（选中带勾，未选划掉，默认全选），× 才是从会话移除；待确认的标签点击去确认。
* **11 粘贴文件**：新增 `composables/usePasteFiles.ts`。智能助手输入框，以及翻译、会议纪要首页上传区与智能审核上传区，都支持 Ctrl+V 粘贴文件（资源管理器复制的文件、截图），与拖入走同一流程。截图命名为“截图-时间.png”；剪贴板里只有文字时照常粘贴。
