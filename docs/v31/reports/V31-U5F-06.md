# V31-U5F-06 设置：自动保存、模型预设、法规同步迁移、默认亮色

2026-11-06 · Sonnet 5.5 · 设计见 [V31-U5F.md](../design/V31-U5F.md) 第六节。只改前端，无迁移、无后端改动。

## 改了什么

* **16 模型预设**：模型页在现有卡片后增加 DeepSeek、智谱 GLM、Kimi、通义千问四张预设卡（接口地址、推荐模型名已填，可改，用户只填 API 密钥），每张提示网络出口须放行的域名。“测试并启用”走原有创建接口：后端先测连接与结构化输出，都通过才创建并启用，失败不创建，原因显示在卡片上。已添加同名模型的厂商不再显示预设卡。最后一张改名“自定义模型”，打开原完整表单。预设的 max_tokens：DeepSeek / 通义 8192，智谱 / Kimi 16000，价格留 0，可在编辑里改。
* **17 自动保存**：新增 `utils/autosave.ts`（`useAutoSave`：立即或停顿 1 秒后保存，离开页面时补发）与 `components/SaveState.vue`（保存中 / 已保存 / 保存失败·重试）。个人每日上限、备份时间与份数、保留期、公司说明改为自动保存；下拉与时间选择即存，数字与文字停顿 1 秒或失焦即存。删除底部“有未保存的修改”栏（`UnsavedBar.vue`）。仍需确认的：缩短保留期（二次确认，取消则还原）、模型密钥（先测通）、修改密码、开启法规同步（弹窗说明会访问外网）。其余分页（脱敏、知识库、范本、法规开关、个人、登录设备）原本就是即时保存；“角色”与范本等弹窗表单保留弹窗内确认，不属于页面级“未保存”。
* **18 法规同步**：从“数据”页移到“法规库”页顶部“自动更新”：开关、频率（`sys.lawsync`）、上次运行、结果、立即同步、待确认变更入口（`content.laws`）。法规库分页对只有 `sys.lawsync` 的人也可见，此时只显示自动更新一节；“数据”分页只对 `sys.data` 可见。`LAWSYNC_FAILED` 提醒的去处改为法规库（后端文案本来就写“设置 → 法规库”）。
* **20 默认亮色**：`index.html` 首屏脚本与 `stores/appearance.ts` 的默认外壳改为亮色；本机已存过外观的保持原选择（只有改过才会写入存储）。
