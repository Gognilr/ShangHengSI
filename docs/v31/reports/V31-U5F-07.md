# V31-U5F-07 角色权限与登录设备

2026-11-06 · Opus 5.5 · 设计见 [V31-U5F.md](../design/V31-U5F.md) 第七节，用户确认见 V31Q-105，口径记为 V31Q-107。与 V31-U5F-05 并行，未改会议纪要 / 转写 / 逐字稿的文件。

## 改了什么

**7.1 角色权限**

* 权限点 17 个固定在 `backend/app/security/permissions.py`（使用 5、内容维护 5、脱敏维护 3、系统 4），前端 `utils/permissions.ts` 同一份代码。
* 迁移 0038：建 `roles`、`user_roles`，去掉 `users.role`；旧角色迁入后权限不变（普通用户 → 普通用户；业务 / 系统管理员 → 普通用户 + 对应管理角色；兼任 → 三个都有）。降级按是否持有内置管理角色还原。
* 后端各管理接口改为 `permissions.require(...)` 按权限点校验，`require_sys_admin / require_biz_admin / require_admin` 已删除。数据页的法规同步开关（`sys.lawsync`）与备份、保留期、系统状态（`sys.data`）拆开；`/admin/terms` 按种类区分“已记住的名称”与“自定义敏感词”。
* “使用”类权限只拦新建与发往云端：智能审核的新建、发起审核、追问；助手按会话用途（对话 / 会议纪要）；任何会话里的云端翻译；导出报告、批注版、修订版、助手导出、逐字稿。本人已有内容仍可查看；本地翻译不设权限。
* 管理员提醒改为按权限点分配。
* 安全底线不变：任务和会话接口仍按 owner_id 校验，非本人 404，与权限无关。
* 设置 → 管理新增“角色”分页：列出角色、权限与人数，可新建、编辑、删除自定义角色。内置角色不能删；“系统管理员”的“账号与角色”勾选锁定；在用的角色不能删。账号页改为多选角色。
* 侧栏菜单、设置分页、各分页内的分区、全局搜索、提醒的“去处理”都按权限点显示。没有智能助手权限时，首页依次退到智能审核、会议纪要、翻译。

**7.2 登录设备**

* `sessions` 增加对外 id、浏览器标识、新 IP 提醒；`users` 增加最近登录 IP。
* 设置 → 个人新增“登录设备”：浏览器（如“Edge 130 · Windows”）、IP、登录时间、最近活动，标出本机；可退出此设备、退出其他全部设备。别人的会话 id 一律 404。
* 新 IP 提醒：本账号其他在线会话的 IP 都与新登录不同时，给这些会话记一条提醒。页面每分钟用 `/auth/notice` 查询（只查，不顺延会话），顶部显示“你的账号刚在 x 登录……”，可“退出其他设备”或“是我本人”。
* 账号列表显示最近登录时间、IP 与在线处数；“强制下线”删除此人全部会话。
* 修改密码后其他设备退出（原已如此），成功提示里写明。
