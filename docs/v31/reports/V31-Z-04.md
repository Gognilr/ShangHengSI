## 三、本次修复

1. **追问被永久拦截（V31Q-119）**：Z-03 rc3 容量复核中 500 字追问“预览 0 项、发送被 MAP 3 项拦截”。本机用同一段文字复现：上一条追问对实体识别误报的“联系人”“索赔”选了替换，代号写进任务对照表；文件正文里同一文字照常存在，出口复检据此拦截，此后该任务的追问与重新审核全部发不出去。修法在 `engine.load_real_values` 一处：追问代号的值若在文件正文出现且没有正文代号，不作为 MAP 依据（正文在审核时已随文件外发，问题里的同一文字仍按对照表替换）。修后同一场景两次追问都发出。智能助手的同类情形另记 V31Q-120 待你定。
2. **旧浏览器白屏（V31Q-117）**：`frontend/index.html` 加一段 ES5 检测，浏览器过旧时显示“当前浏览器版本过低……请在 Windows 10 / 11 上用最新版 Microsoft Edge 打开”。

测试：test_chat、test_assistant_chat、test_v2b_chat_project、test_v2b_derived、test_recheck、test_keep_terms、test_gateway、test_gateway_stream、test_redaction_golden、test_a03_outbound 851 通过，前端构建通过。没有新增测试函数。
