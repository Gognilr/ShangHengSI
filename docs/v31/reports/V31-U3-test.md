**发现并已修复**
1. 工具条第一行溢出。1366 宽时主文件名被挤到 80px；出现轮次下拉后，右侧“重新审核”和“⋯”被挤出屏幕（溢出 138px）。改为：
   - 工具条宽度不足 1200px 时，回执条只显示保护数与还原比例（复检、拦截仍在弹层里），“另有 N 个附件”改放进文件名的悬停提示；
   - 轮次下拉框内只显示“第 N 轮”（112px），展开的选项仍是完整文字；
   - 文件名最小宽度 120px。
   - 复测 1366、1440、1920 三个宽度均无溢出。（ResultToolbar.vue、ReceiptStrip.vue）
2. 工具条第一行高 60px（设计 48px）。原因是全局 `.actions` 带 `margin-top: 24px`，工具条和 ZoneHeader 用了同一个类名。两处改为显式 `margin: 0 0 0 auto`。
3. 预填追问时输入框没有焦点：抽屉打开动画结束时 el-drawer 把焦点移到了抽屉本身。改为在 opened 事件后再聚焦并把光标放到末尾。（ChatPanel.vue）
4. 追问回复中，本机计算卡片后多出一个空行（算式行末的换行被原样显示）。卡片后紧跟的换行不再显示。（ChatPanel.vue）
5. 重新审核对话框只有一个模型时，说明文字和模型名挤在同一行。说明改为独占一行。（ReRunDialog.vue）
6. 切换轮次时状态标签有一次缩放闪现（el-tag 自带的出现动画）。加 `disable-transitions`。
