# 商衡SI V3.1 整体方案

2026-11-01 · Opus 5.5 起草（V31-00）· **草稿，待用户确认**

依据：2026-11-01 会话讨论形成的 44 项整改与三项已定决定（docs/v3/open\_questions.md 的 V3Q-26 默认替换、V3Q-27 V3.1 单独发版、V3Q-28 光幕视觉方向）；概念稿与动效样张 docs/proposals/lumen-2026-11-01/；《商衡SI-脱敏总文档》第二部分 P0 三项施工设计；当前代码 `1d11b90`。需用户决定的事项见 [open\_questions.md](open_questions.md)。

## 一、目标

V3.0 让审核结果能落到 Word 里。V3.1 解决三件事，让系统“往返无损、少点鼠标、看着就想用”：

1. **回程完整性**：模型回来的每段文字，要么完全还原，要么明确标出，绝不把可疑文字写进合同（修订版残留风险在 V3.0 是已知限制，V3Q-27）。
2. **解放双手**：不确定项默认替换、人工可选（V3Q-26）；拖入即解析；确认页变成一张回执，正常文件只需点一次确认。
3. **光幕界面**：深色外壳加白色纸面、苹果蓝、三层动效、审核中仪式；外壳与特效级别可选，弱电脑自动降级（V3Q-28）。

另含脱敏加固（P0 三项等）和“可证明”能力（外发回执、双指标评测）。

## 三、关键设计决定（细节在各批设计文档中展开）

1. **代号格式**：审核外发的主体、人员、项目、编号代号统一加方括号，`我方` 改为 `[我方]`；旧任务的对照表保持原代号，还原按对照表走，不迁移旧数据。是否执行以 R-01 体检数据为准（R-00 定稿）。
2. **还原原则**：有方括号或下划线、不会与普通词混淆的写法自动还原；可能是普通词的写法（如“人员1”）只标出、不替换；对照表中不存在的代号标为“模型提到了文件中没有的对象”。修订版中任何带标记的建议一律改为批注。
3. **默认替换**：不确定项替换为 `[名称_n]` 或 `[专有名词_n]`，确认页折叠显示，用户可改回“保留原文”；保留过的词进入术语记忆（本人立即生效，公司共享须另一用户也保留过或业务管理员认可，带企业后缀、人名结构、已记住的敏感名称永不进入）。
4. **拖入即解析**：第一次拖入即建草稿任务并解析，页面不跳走；多次拖入加入同一任务、共用代号；删除可在 5 秒内撤销，之后服务器真删；永不自动跳页（V31Q-02）。
5. **光幕外观**：外壳夜幕 / 浅色，特效自动 / 完整 / 精简 / 关闭，存在浏览器本地；合同纸面始终白底；动效只动位移与透明度，循环动画只在等待期间出现；动画从不推迟结果出现（结果就绪即可操作，仪式是叠加层）。
6. **字体**：倾向 MiSans 加 JetBrains Mono，本地托管、按需分片加载；MiSans 许可证核实后定，备选思源黑体（V31Q-03）。

## 四、安全不变量（每批审核时逐条核对）

沿用 docs/v3/PLAN.md 第四节全部条目，另加：

1. 默认替换只会多替换、不会少替换；术语记忆与“保留原文”只影响不确定项，永不撤销规则或签约方识别的替换；出口复检照常全量执行。
2. 代号格式变更后，复检的代号遮盖、对照表比对、A-03 外发计数口径不变。
3. 还原只替换对照表中存在的代号；无法确定的写法只标出，不猜测替换。
4. 拖入即解析只上传用户拖入或选中的文件；删除文件在撤销期过后删除原件、解析结果与对照表中仅属于该文件的条目。
5. 外观设置只存浏览器本地，不发送到服务器；字体等静态资源全部本地托管，不访问外部网站。
6. 回程体检与双指标评测只使用虚构样本，经网关与出口复检调用模型。

## 八、不做

* 判为有害的做法：金额按系数缩放、用逼真的虚构公司名替换主体、地址细化到片区、跨页飞线与缩略图导航、外发密码学存证。
* 多套皮肤（只做夜幕 / 浅色两种外壳）；深色纸面。
* 更换组件库（保留 Element Plus，深度换肤）；引入 React 或照搬第三方付费组件代码（只借鉴设计思路）。
* 跨任务代号延续、交易项目包（与任务隔离冲突）。
