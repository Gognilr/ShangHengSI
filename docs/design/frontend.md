# 商衡SI 前端界面规范 · 澄明二版「衡线」

V3.6.0 起按本规范实现。页面以澄明设计和澄明二版定稿为基础，功能与交互以 [SPEC](../SPEC.md) 为准。标志见 [衡线资产](v35/brand/README.md)，页面见 [二版效果稿](v36/preview.html)。[二版草案](v36/澄明二版设计规范-草案.md)保留阶段设计过程。

## 二、设计目标与原则

**目标**：打开就觉得清爽、有精神、值得信任；每一屏一眼看懂“这是什么、现在怎样、我该做什么”。

**四条原则**

1. **分层**：画布是浅冷灰，内容放在白色卡片上，浮层再高一层。页面、对象、临时的东西一眼分得开。
2. **颜色要表达意思**：青 = 本机 / 安全 / 主要操作；紫 = 大模型；红黄蓝 = 严重程度；绿 = 流程完成；各模块有识别色。颜色用“浅底 + 深字”铺开，不只是一个圆点。
3. **字够大、层级分明**：正文 14px 起，阅读 15px，页标题 24px，首页问候 36px。12px 只给徽标和计数。
4. **动效说明因果**：东西从它的来源处出现，状态变化有过渡，进行中的事在流动。不做无意义的循环装饰。

**高级感从哪里来**（每页自查）

| 做法 | 具体要求 |
|-|-|
| 留白 | 区块间距 40～56px；一屏只有一个视觉中心 |
| 元素少而准 | 每个区域只有一个主按钮；同一件事只说一次；进度只出现在一处 |
| 字号反差 | 标题与正文至少差两档；数字用等宽、加粗 |
| 材质 | 只有三层：画布、卡片、浮层。阴影柔和，带一点冷色 |
| 色彩集中 | 大面积是中性色，颜色只出现在有意义的地方，但出现时要铺开、要饱满 |
| 动效有分寸 | 进入 320～520ms，带弹性；悬停 200ms；不做闪烁、旋转等炫技 |
| 对齐 | 4px 网格；同一列的左边缘严格对齐；图标与文字基线居中 |

## 三、品牌与标志

### 3.1 名称与寓意

* **商衡**：“商”是商务往来；“衡”是秤杆，引申为把条款放平了称一称，公允地看双方。
* **SI**：Secure Intelligence，安全的智能（SPEC 第 1 节）。
* 产品机制：原件留在本机，真实名称遮住之后才交给模型，结果回来再在本机还原。

标志要把这三层意思装进一个简单图形。

### 3.2 设计要求

1. 寓意能用一句话讲清。
2. 16px（浏览器标签页）仍能认出；单色可用（Word 报告页眉、打印件）。
3. 最多两种品牌色：衡青加灵紫。渐变只用在应用图标底块。
4. 几何构造：24 网格，笔画为 2 的倍数，圆角统一。
5. 不用以下图形：
   * 盾牌、锁、天平实物（现在的 favicon 是盾牌加天平，显得土）；
   * 彩带交织、单独的四角星（这是常见 AI 产品的标志手法，没有辨识度）。

### 3.3 定稿「衡线」

纸框中部的衡青横线伸出纸边，右上角的灵紫星点代表模型。在标签页等小尺寸使用简化版本，标准、大尺寸和单色版使用 F-00 定稿资产。

### 3.4 交付规格（F-00）

* **SVG 源文件**：彩色、单色（墨）、反白（深底）三版。
* **favicon.svg**：深色标签栏下换亮一档。
* **应用图标**：180、192、512 的 PNG，配 manifest。
* **字标组合**：横排为“图形 + 商衡 + SI”，竖排为图形在上。文字转成路径，不依赖字体。
* **尺寸与留白**：
  * 图形最小 16px，横排组合最小 96px 宽；
  * 四周留白不小于横线高度的 2 倍。
* **不得**：拉伸、改色、加阴影、旋转（404 彩蛋除外）、放在花底上。
* **使用位置**：
  * 侧栏顶部：横排，图形 28px；
  * 登录页：图形 96px，带动效；
  * 首页问候：图形 44px，带动效；
  * favicon；
  * Word 报告封面与页眉：单色；
  * 404 页。

| 名称 | 实色 | 用在 |

| 衡青（主色） | 按钮 #078A76，图标与进度 #10A58C | 主要操作、选中、焦点光圈、链接、进度，以及一切“本机 / 安全”的标识 |
| 灵紫（模型） | #6D5BF6 | **只用于和大模型有关的东西**：模型徽标、模型步骤、生成中、“AI 建议”分区、AI 视野。看到紫色就知道这部分出过网关 |
| 严重 / 高 | #E5484D | 严重问题、高等级、失败 |

脱敏类别色沿用七类，并提亮一档：单位蓝、人名紫、联系方式青、证件橙、地址橄榄、金额琥珀、其他灰。深色模式全部单独取值，不用反色。

令牌的实际取值与兼容映射以 `frontend/src/styles/theme.css` 为准。原有 `--si-ink-*`、`--si-hair-*`、`--si-surface-*` 保留名称并按澄明取值。`--si-accent` 映射到灵紫，`--si-ok` 用于表示流程完成。选中与悬停底为半透明色（V35Q-21）。



### 4.3 渐变与氛围光（只有这些地方可以用）

1. 标志的应用图标底块。
2. 头像。
3. **氛围光**：只在首页顶部和登录页品牌区。
   * 用衡青、灵紫、少量天蓝的大块径向渐变，浅色不透明度不超过 12%，深色不超过 18%；
   * 24 秒缓慢漂移；
   * 只动 transform，不用 filter 模糊；
   * 精简档静止，关闭档不显示。
4. 工具条往返线的光点与模型回到本机的双色线段。
5. 模型“正在生成”的指示。

静止的按钮、卡片、页面背景一律用纯色。

### 4.4 对比度与新增令牌

按 WCAG 2.x 相对亮度公式一次性核算（与 leonardo 的对比度算法等价）。半透明浅底先叠到所在的纸面或卡片上再算；文字要求 ≥ 4.5，图形（圆点、线段）要求 ≥ 3。核算脚本与全部结果见 docs/v36/reports/V36-F-00.md。

**深色底：全部达标，不改取值。** 灵紫实色 5.46，灵紫深字在浅紫底上 7.31，辅助字在浅紫底、浅青底上 5.11、5.01；七类胶囊字 5.34～7.05；占位点 3.25。

**浅色底：七类胶囊字不达标，新增深字令牌。** 原来胶囊文字直接用类别色，在各自浅底上只有 2.76～4.16。保持色相、降低明度到 4.6 左右：

| 类别 | 原色（继续用于圆点、描边、分段条） | 在浅底上 | 新增 `--si-k-*-ink`（胶囊文字） | 在浅底上 |
|-|-|-|-|-|
| 单位 org | #2F6BF0 | 4.07 | #1E5FEF | 4.63 |
| 人名 person | #8B4CF0 | 4.16 | #8340EF | 4.63 |
| 联系方式 contact | #0E97B2 | 3.08 | #0B778C | 4.65 |
| 证件 id | #E5711C | 2.76 | #AB5414 | 4.63 |
| 地址 addr | #6E8B1F | 3.50 | #5E761A | 4.60 |
| 金额 amount | #C27A05 | 3.13 | #9A6104 | 4.66 |
| 其他 other | #6B7686 | 4.06 | #636D7C | 4.62 |

深色外壳里 `--si-k-*-ink` 等于原色。原色作圆点放在白底上均 ≥ 3.13，可以继续用。

**往返线占位色。** “未到”的空心点原用 `--si-ink-4`（#94A0B2），在白卡上 2.65，不足 3。新增 `--si-trip-idle`：浅色 #8794A8（3.07），深色沿用 #5E6A7B（3.25）。同时新增 `--si-trip-l`（= 衡青图标色）、`--si-trip-m`（= 灵紫），往返线只用这三个令牌。

**地带底色。** 新增 `--si-zone-l`、`--si-zone-m`：浅色为浅青、浅紫底各混 28%、22% 卡片白，避免整块区域过艳；深色直接用浅青、浅紫底。辅助字在两种地带上均 ≥ 4.75。

以上取值由 V36-F-01 写进 theme.css。DESIGN.md 格式的令牌摘要见 [DESIGN.md](v36/DESIGN.md)。

票赭浅色 #9A5B3C、深色 #C98463，模块浅底为 `--si-m-inv-soft`。浅色线条和文字在白底、浅底上分别为 5.34 和 4.59，深色为 5.92 和 4.81（V36Q-22）。

## 六、表面、圆角、阴影、间距、图标与插画

**表面层级**

| 层 | 外观 | 用于 |
|-|-|-|
| 画布 | 画布色 | 页面背景 |
| 卡片 | 白底，1px 细线，极浅阴影 | 一切成组的内容 |
| 抬起 | 阴影加深，上移 3px | 可点卡片的悬停状态、首页输入框 |
| 浮层 | 最深一档阴影 | 下拉、弹窗、抽屉、全局搜索、Toast |
| 纸面 | 纸色，纸面阴影，放在凹面舞台上 | 原文预览、译文、逐字稿 |

**圆角**：控件 10，卡片 14，大卡片 18，首页输入框 24，浮层 16，纸面 6，徽标全圆。

**毛玻璃**：只在完整档使用，只有两处——首页输入框、全局搜索浮层。精简和关闭档用实色。基线机器没有显卡，不能处处模糊。

**间距**：4 为基数。
* 卡片内边距 20～24，卡片之间 16；
* 区块之间 40～56；
* 页面两侧 40（1366 以下 28）。

**控件高度**：默认 36，小 30，大 44。表格行高约 56。

**图标**：lucide，线宽 1.75。
* 尺寸：按钮内 16，导航 18，卡片标题 20，空状态 24（放在 56px 的浅色圆内）。
* 模块图标统一放在 40～44px 的圆角方块里，底色用模块浅底。

**插画**：用于模块入口、工作台卡片、空状态和 404 页。
* 线条风格，用模块色，单个不超过 30 个元素；
* 悬停时才动，只动 transform 和 opacity；
* 放在 components/brand/illus/。

## 七、布局与全站规则

左侧栏默认宽 248px，可拖宽至 220～320px，也可收起为 68px 图标栏。右侧是画布。工作台以输入框为中心；入口依模块物件安排拖放或选项；工作区以工具条和纸面、结果或证据分栏；列表以筛选和行卡为主；设置以分组导航与主区组织。

工作区在顶部工具条显示进度，列表和文件标签用迷你线，真实数量跟在当前站旁。检查完成后再给结论，扫描仍在识别时标明结果的覆盖范围。文件、投标人、会议、项目各用一张卡，展开才看明细。

1. **往返线是唯一的进度语言。** 旧的 StepBar、ReviewSteps、状态徽标里的进度、各页自画的进度条，全部换成 SiTrip。真实的数量进度（第 23 / 76 页、62%）作为当前站旁边的文字，不另画一条进度条。
2. **两个地带。**
   * 本机产出放在青色地带：浅青底、锁或计算器图标。包括原文、本机计算、遮住胶囊、本机检查结论、逐字稿。
   * 模型产出放在紫色地带：浅紫底、星点图标。包括 AI 建议、模型补查、纪要草稿、云端译文、对话回答。
   * 地带是区块级的底色，不是一行标题。现有的 ZoneHeader 扩展为 `SiZone`（标题加区块底）。
3. **每个模块有自己的物件。** 审核是一叠纸，合同对比是并排的两张纸，标书是开标桌上的几份标书，纪要是声纹带，翻译是对开的两页，发票管家是夹着一叠票的票夹（V36-I）。入口页从物件开始，不再共用“虚线框加最近列表”。物件插画放在 components/brand/illus/，规格见第六节：线条、模块色、单个不超过 30 个元素、悬停才动。
4. **每页一张主图。** 主图来自产品机制，例如揭幕、地形条、缝线、泳道、出口地图。主图只用现有数据；缺的从现有表聚合，不为它新增统计表；第十九节列出每张图的数据来源。
5. **能画的不写成句子。**
   * 计数用迷你柱形或圆环；
   * 进度用往返线；
   * 构成用分段条；
   * 句子只留给原因和下一步该做什么。
6. **默认件全部换皮。** Element 默认件不得原样出现在页面上，替换关系见第九节。

## 八、逐页设计

功能与权限以 [SPEC](../SPEC.md) 为准。

### 8.0 外壳与全局搜索

* **侧栏自上而下**：
  1. 标志组合；
  2. “新建会话”：青色浅底大按钮；
  3. 工作台；
  4. 文件审查：文件审核、合同对比、标书初审；
  5. 工具：会议纪要、翻译、发票管家；
  6. 历史记录；
  7. 搜索（Ctrl K）；
  8. 近期会话：最多 8 条，每条只画往返线的当前站，颜色和光圈见第十七节，悬停显示完整往返线；
  9. 账号行。
* **选中**：选中底色，字重 600，图标变成模块色；工作台、历史记录、搜索没有模块色，用衡青。
* **菜单右侧的数字**：只显示**等你处理的数量**（例如待确认脱敏 2），不显示总数。
* **账号行**：显示头像、姓名和所兼角色。点开菜单可查看管理员提醒、设置外观、修改密码及退出。管理员提醒用琥珀色圆点。
* **全局搜索**：屏幕居中的浮层，宽 640，结果按模块分组，每条带迷你往返线和最近活动时间。分组标题用模块色识别方块，键盘上下选择、回车打开。

### 8.1 登录

* **布局**：左右分屏。
* **左侧品牌区（55%）**：
  * 深色底，加衡青和灵紫的氛围光；
  * 标志 96px 带开场动效；
  * 主标题 40px：“商务文件的安全初审助手”；
  * 副标题 16px：“原件留在本机，真实名称遮住后才交给模型，结果回来在本机还原。”；
  * 页脚：版本号与“仅限公司内网使用”。
* **右侧**：400 宽的登录卡。
  * 标题“登录”24px，输入框 44 高，“记住账号”，满宽主按钮；
  * 错误显示在对应字段下方；
* **宽度小于 1280** 时隐去左侧，只留登录卡和标志。

* **主图**：品牌区的三个要点换成一条会走的往返线，作为开场动效：纸 → 遮住 → 星点 → 还原，约 2.6 秒走完后定格。
  * 每站下面一行字：原件不出内网、名称发出前遮住、模型只见代号、回到本机还原；每站再加一行辅助字。四个站点落在四列说明的中心，底线两端伸出最外两站（F-00）。
  * 线色：前半青，过“遮住”后变紫，到“还原”前变回青（F-00）。
  * 衡线标志 96px 的开场动效与这条线首尾相接：标志的横线伸出纸边，延长成往返线。
* **首次改密并进登录卡**（用户 2026-11-26，V36Q-11）：须改密时，登录成功后同一张卡切到第二步，不进入主框架。须改密包括首次登录和被管理员重置密码。
  * **卡头**：步骤“登录 ✓ — 设置新密码”，标题“设置新密码”，一句说明“这是初始密码，请换成只有你知道的密码”。
  * **字段**：新密码、再次输入。免填原密码（V321Q-36）；密码规则写在字段下方，以后端的校验和错误提示为准。
  * **按钮**：主按钮“保存并进入”，文字按钮“退出登录”。错误显示在对应字段下方，例如两次不一致、新旧相同、强度不够。
  * **浏览器记住新密码**：第二步带一个隐藏的用户名字段（`autocomplete="username"`），两个密码框用 `autocomplete="new-password"`，浏览器密码管理器会提示更新保存的密码。

  * **成功后**：进入原来要去的页面或首页，Toast“密码已更新”。其他设备上的登录已由后端失效。
  * **刷新与直接访问**：已登录但须改密的会话（例如在第二步刷新页面），路由守卫送回登录页第二步，不再送去首页。

* 精简档直接显示定格的线。

| 就地编辑 | 主图或卡片上的单个数值 | 跳转到别的表单 | 点该数值所在的块弹出小卡：一个控件、一句说明、自动保存状态、“完成”；Esc 或再点一次关闭；只放一个设置项（F-02） |
| 逐步检查 | 连接测试、接入新模型一类的多步检查 | 每步一张通过 / 失败提示卡 | 行内一列步骤：未到空心点、进行中转圈、通过打勾、失败红叉加原因；前一步失败，后面的写“未测”，不重复同一个原因（F-02） |
| `SiSpark` | 迷你柱形 | 数字句子 | 按天的计数，周末降透明度；零值画 2px 底线；每根带悬停提示 |
| `SiRing` | 环形用量 | 用量进度条 | 直径 40，线宽 4；超过 85% 变琥珀 |
| `SiStack` | 分段条 | 构成类句子 | 七类脱敏、用途、存储构成；图例在下，点一段可筛选 |
| `SiCount` | 数字滚动 | — | 已有；精简档直接显示终值 |
| `SiStagger` | 依次弹入 | — | 待办、新问题、新行从下方弹入，每项晚 45ms，最多 8 项 |
| 物件插画 | 入口、空状态、404 | 通用空状态图标 | 第七节第 3 条 |
| `EmptyState` | 空状态 | el-empty（2 个文件） | 改用模块物件插画，一句标题、一句说明、一个按钮 |

**取舍说明**

* 动效模式借 Magic UI 的 NumberTicker、AnimatedList、BlurFade，用 Vue 重写，不引依赖。
* BlurFade 只借节奏，不用模糊：基线机器没有显卡，页面进入仍是淡入加上浮 10px（V36Q-05）。
* 跑马灯、地球、流光按钮一类营销效果不用。
* 页面中不再直接出现 `<el-tag>`、`<el-alert>`、`<el-empty>`；el-table 只留在上表允许的场合。走查时核对，不为此写测试。

## 十、内容与文案：让每一屏一眼看懂

1. **每页一句话**：入口页、列表页和空状态，在标题下写一句话说明这页做什么，不超过 40 字。工作区不写。
2. **标题写对象本身**：用文件名、项目名、会议名，不写“任务详情”。
3. **状态写三件事**：在做什么、真实进度、你能做什么。例如“正在本机识别扫描页 · 第 23 / 76 页 · 可以离开页面”。
4. **数字带对象**：徽标里可以写“严重 2”，句子里写“2 个严重问题”。
5. **结论在前，理由在后**：问题卡片的顺序是一句话结论 → 为什么 → 依据与位置 → 建议条文。
6. **本机的和模型的分开说**：本机的用青色，写“本机计算 · 结果确定”；模型的用紫色，写“AI 建议 · 请核实”。
7. **长度**：卡片标题不超过 24 字；说明超过 80 字时折叠，带“展开”。
8. **不写内部术语**：

| 内部说法 | 界面写法 |
|-|-|
| 实体、敏感实体 | 名称、金额等 |
| 脱敏（动作） | 遮住；页标题和设置项里仍可用“脱敏” |
| 不确定项 | 需要你看一眼的 |
| 出口复检 | 发送前复检 |
| 还原 | 还原真实名称 |
| 外发策略 local_only | 只在本机处理 |
| 解析 | 读取 |
| 运行、run | 第 n 轮审核 |
| L-INFO | 无法核验 |

9. **全站文字**：全角标点；中文与数字、英文之间留空格；不用感叹号和“您”；界面不出现“审核通过、无风险、已安全、零泄露”；SPEC 规定的文字逐字照抄。

## 十一、动效

| 令牌 | 值 | 用于 |
|-|-|-|
| `--ease-out` | cubic-bezier(.22,1,.36,1) | 进入、移动（默认） |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | 小元素弹入、图标、单选点、Toast |
| `--ease-io` | cubic-bezier(.65,0,.35,1) | 循环指示 |
| 时长 | 120 / 200 / 320 / 520ms | 按下 / 颜色变化 / 移动 / 页面进入 |

**规定的动效**

* 页面进入：淡入并上浮 10px。
* 卡片依次浮现：每张晚 45ms，最多 8 张。
* 可点卡片悬停：见第九节。
* 新问题弹入：从下方弹入，带轻微过冲。
* 滑块、下划线：平移。
* 统计数字：从 0 滚动到目标值。
* 加载：同形骨架，表格骨架带光泽，卡片轮廓静态；生成与计算的等待见 8.10。
* 整块内容到达（如标书原件页图）：由模糊变清晰淡入（`.si-blur-in`，借 BlurFade）；精简档只淡入，关闭档直接出现。
* 抽屉：滑入 320ms。弹窗：从 0.96 放大进入。
* 原文定位：平滑滚动后闪一次。

**品牌时刻**（四处）

1. 标志开场：登录页与首页问候。
2. 氛围光漂移：同样只在登录页与首页。
3. 纸面扫描线：读取文件、模型审核时。
4. 还原扫描：完成的轮次首次打开时。

| 动效 | 规定 | 精简档 | 关闭档 |
|-|-|-|-|
| 走线 | 工具条和地图上，一个光点沿线前进，过复检后由青变紫，回到还原时变回青。只在状态变化时走一次，不循环 | 不走光点，站点直接切换状态 | 同精简 |
| 还原扫描 | 第四个品牌时刻。某一轮结果第一次打开时，一道青色扫描线自上而下掠过纸面一次（约 1.7 秒），经过处的代号胶囊沿横轴翻成真名。翻转期间代号与真名叠在同一格，翻完后代号格收起，真名按自身宽度排版，只在结束时重排一次（F-00）。同一轮再次打开不再播放 | 定格终态 | 不播放 |
| 揭幕滑块 | 拖动时纸面跟手，无缓动；松手不回弹 | 同完整 | 同完整 |
| 缎带 | 合同对比两稿之间的缎带随滚动重绘，用 requestAnimationFrame 节流，只画可见的部分。新增或删除的一侧没有对应文字时，缎带在那一侧收成一点（F-00） | 滚动时隐去，停止后再重绘 | 不画缎带，只保留两边高亮 |
| 地图点亮 | 模型页首次进入视口时走一遍，节点依次点亮 | 不走 | 不走 |
| 票夹落入（V36-I） | 拖入时夹片张开、票扇展开；松手后文件化作小票卡依次落进票夹，每张晚 45 毫秒，最多 8 张，其余写“+n” | 直接显示已加入的张数 | 同精简 |
| 扫票（V36-I） | 识别中的那一行带一道青色扫描光条，识别完成时消失，金额从 0 滚到终值；新识别出的行从下方弹入；下载完成时按钮内划出一次勾号 | 不播放光条、滚动与勾号，直接显示 | 同精简，并取消弹入 |

**四档**（沿用自动 / 完整 / 精简 / 关闭和 data-fx 机制）

* **完整**：全部开启。
* **精简**：去掉依次浮现、数字滚动、悬停转动、氛围光漂移和毛玻璃；品牌时刻定格在终态。
* **关闭**：只保留 120ms 内的淡入淡出。
* **自动**：按第十五节的判定规则选档。

**性能底线**：
* 只动 transform 和 opacity；
* SVG 路径重绘每帧最多一次，不用 filter 模糊做氛围光；
* 完整档在开发机上不低于 55 帧，精简档在 `--disable-gpu` 下不低于 30 帧。

## 十二、状态与颜色的对应

| 枚举 | 对应 |
|-|-|
| 严重程度 | 高为红，中为琥珀，低为天蓝。用浅底徽标加圆点，原文高亮用同色 |
| 任务状态 | 进行中沿用当前站的本机青或模型紫，状态由光圈和文字表达。等你与被拦截用琥珀，失败用红，已停止和已过期用中性色。完整映射见第十七节 |

## 十三、安全相关的写法

1. 不使用 `v-html`、`innerHTML`、`ElMessageBox` 的 `dangerouslyUseHTMLString`。外发文本、原文、原文引用、模型返回的文字都按纯文本显示（文本插值、`<pre>` 或 `white-space: pre-wrap`）。需要高亮片段时，拆成片段数组逐个插值。
2. 不用 `console.log` 等输出任何内容；提交的代码中不留 `console.*`。
3. 本地存储（`localStorage`）只能存界面偏好：上次的立场和来源（Q-51）、登录页记住的用户名（`si.login.username`，SPEC 6.1；密码只交给浏览器密码管理器，不进本地存储）、侧栏收起与宽度（`si.sidebar.collapsed`、`si.sidebar.width`）、审核结果问题栏宽度（`si.review.findingsWidth`）、外观设置（`si.appearance`，第十五节）。工作文件夹的授权句柄存本浏览器 IndexedDB（库 `si`、表 `prefs`、键 `workFolder`）。现场录音的防丢分片可以暂存（IndexedDB 库 `si-recording`，上传成功或放弃即清除，界面写明“保存到本机浏览器”，V31Q-106）。发票管家可按账号记录当前批次 ID，以便返回本页后向后端查询，清除或过期后随即移除。其余不得存密码、文件内容、名称、问题、对照表、文件夹路径、文件名或任何接口返回的业务数据。读写包在 try/catch 中，读不到按默认值。
4. URL 中只放 ID 和页码、日期等筛选条件，不放文件名、公司名等文字。
5. 所有请求经 `api/http.ts` 发出，不在组件中直接用 `fetch`。每个后端资源在 `api/` 下一个文件，接口类型与后端返回字段同名。
6. 前端检查（文件数量、大小、扩展名、必填项）只是提示，后端一定会再检查；不要因为前端检查过就省略对接口错误的处理。
7. 外发栏（对照视图、外发文本）显示的内容只来自后端返回，前端不拼接、不替换；对照视图只用于阅读，不影响实际发送的内容。

## 十四、代码组织

1. 页面放在 `views/`，子组件放在 `components/`，使用 `<script setup lang="ts">` 与 `<style scoped>`。动态尺寸可用绑定样式，Element Plus 局部覆盖用 `:deep()`。主题与动效选择器直接写 `html[data-fx="…"] .x`，避免把 `html` 包在 `:global()` 中。
2. `styles/fonts.css` 管理本地字体，`theme.css` 定义令牌与 Element Plus 映射，`skin.css` 集中定义控件外观，`common.css` 定义页面与组件共用样式，`motion.css` 定义动效及过渡。页面从令牌取色。
3. 接口定义放在 `api/`，标签映射统一放在 `utils/labels.ts`，时间经 `utils/time.ts` 格式化，显示时区为 Asia/Shanghai。导出通过 `utils/save.ts` 的 `saveBlob` 保存。
4. 往返线状态统一由 `utils/trip.ts` 映射，进行中与待用户处理用不同状态。

## 十五、外观设置

* 「设置 · 个人」支持浅色、深色、跟随系统，字号标准、较大、特大，动效自动、完整、精简、关闭。修改立即生效，同一浏览器的登录页也使用上次的设置。
* `si.appearance` 仅存外观偏好。默认 `{"shell":"light","fx":"auto","fs":"md"}`，旧值缺少字号时为标准。`index.html` 在样式生效前设置 `data-shell`、`data-fx` 与 `data-fs`，页面启动后由外观 store 接管。
* 自动档依次判断系统减少动态效果（关闭）、软件渲染或核心数不超过 2（精简）、运行中明显掉帧（本次精简），其余为完整。手动档优先。结果可用即显示，动画随工作完成结束。

## 十六、实施与验收

* 前端构建须通过 `npm --prefix frontend run build`，并按任务范围用虚构数据、模拟服务走查。
* 浅色、深色各看 1366 和 1440 宽两种视口。检查页面与操作状态、横向滚动、文字遮挡、键盘焦点和控制台。涉及动效时覆盖自动、完整、精简、关闭四档。截图留在会话中。

* 按适用模块验往返线的进行中、等你、拦截或失败、完成及全程本机。涉及只读聚合接口的任务，各写一条代表性用例并验权限和返回数据范围。

## 十七、往返线

标志「衡线」是纸框中部一道伸出纸边的青线，加上右上角的紫色星点。二版把这道线延长成全站的进度语言：一件工作从本机出发，遮住后经网关到模型，再回到本机还原。界面上处处画的是这一趟往返。

**五站**

| 站 | 在哪里 | 颜色 | 一句话 |
|-|-|-|-|
| 读取 | 本机 | 青 | 解析原件，原件不出内网 |
| 遮住 | 本机 | 青 | 名称、金额换成代号，等你确认 |
| 发送前复检 | 本机 | 青 | 出网前再查一遍 |
| 模型 | 云端 | 紫 | 只见遮住后的文字 |
| 还原 | 本机 | 青 | 回到本机换回真实名称 |

* 线段颜色跟着内容走：读取到复检为青，复检到模型为紫，回到还原时变回青。看颜色就知道这段内容出没出过网关。
* **只在本机的工作只有三站**：读取、本机处理、完成，整条青色。包括外发策略为只在本机处理的任务、本地翻译、只做本机检查的标书、发票管家（V36-I）。这条线本身就在说“没有出去过”。
* **可选的模型步骤**：例如标书的模型补查，未发起时不画紫段；发起后再接上紫段。

**站的状态**：颜色说在哪里，光圈说怎么样。

| 状态 | 画法 |
|-|-|
| 未到 | 占位色空心点，细线 |
| 已过 | 站色实心点，实线 |
| 进行中 | 站色实心点，加呼吸光圈；工具条尺度上有光点沿线前进 |
| 等你 | 琥珀光圈，旁边紧跟一个动作按钮，例如“去确认”“去校对” |
| 被拦截 | 复检站换成琥珀实心，旁边写“发送前复检拦截 n 处” |
| 失败 | 红色实心加叉，旁边写原因与重试 |
| 已停止 | 中性实心点，写“已停止” |

天蓝不再表示进行中，只用于“低”等级与说明。

**三种尺度**

| 尺度 | 用在 | 样子 |
|-|-|-|
| 迷你 | 侧栏近期会话、全局搜索结果、历史记录行、工作台待办、文件标签 | 五个 8px 点，用 2px 短线相连，总宽约 80px；旁边一句当前站的话 |
| 工具条 | 所有工作区顶部 | 站名横排，当前站加粗并带计时；完成后收成一个徽标“已完成 · 用时 1 分 12 秒” |
| 地图 | 设置 · 模型（8.9）、工作台说明浮层 | 本机地带 → 网关四关 → 各模型节点，见 8.9。由 `ExitMap`（components/settings/）画，SiTrip 只做迷你与工具条两种 |

* **无障碍**：迷你尺度用 `role="img"`，`aria-label` 写全，例如“第 2 站 遮住：等你确认”。工具条尺度用 `<ol>`，当前站带 `aria-current="step"`。状态不只靠颜色，光圈、叉号和旁边的文字同时表达。
* **站名按模块换**：

| 模块 | 工具条站名 |
|-|-|
| 文件审核 | 读取 · 确认遮住 · 复检 · 模型审核 · 还原 |
| 对话 | 读取附件 · 遮住 · 复检 · 模型回答 · 还原 |
| 标书初审 | 读取材料 · 识别扫描页 · 本机检查 · 完成；发起补查后接：遮住 · 复检 · 模型补查 · 还原 |
| 会议纪要 | 本机转写 · 校对 · 确认遮住 · 复检 · 生成纪要 · 还原 |
| 翻译（本机） | 读取 · 本机翻译 · 完成 |
| 翻译（云端） | 读取 · 确认遮住 · 复检 · 模型翻译 · 还原 |
| 发票管家（V36-I） | 读取 · 本机识别 · 生成清单 |

  迷你尺度一律压成通用五站（或本机三站），具体站名放在 `aria-label` 和悬停提示里。几站压进同一个通用站时，当前站的状态说了算（F-00）：

| 模块 | 压缩方式 |
|-|-|
| 会议纪要 | 本机转写、校对 → 读取；其余四站一一对应 |
| 标书（本机） | 读取材料 → 读取；识别扫描页、本机检查 → 本机处理；完成 → 完成 |
| 标书（发起补查后） | 读取材料、识别扫描页、本机检查 → 读取；遮住、复检、模型补查、还原一一对应 |
| 翻译（本机） | 三站一一对应 |
| 发票管家（V36-I） | 三站一一对应 |

* **线段颜色**（F-00）：两站都在本机为青；有一端是模型为紫；从模型回到还原的一段前半紫、后半青。只画走过的线段，没走到的用细线占位色。
* **完成徽标**（F-00）：工具条尺度完成后收成“迷你线 + 已完成 · 用时 n”；只在本机的任务在徽标后加“全程本机”。
* **动作按钮**（F-00）：“等你”“被拦截”“失败”三种状态，工具条尺度在当前站名后紧跟一句状态和一个按钮，按钮之后才是未到的站；迷你尺度不带按钮，按钮放在所在行的行尾。

* **状态映射**：状态到站点的对应只写在 `utils/trip.ts` 一处，各页不得自己判断。以文件审核为例：

| 任务 / 轮次状态 | 当前站 |
|-|-|
| draft、parsing | 读取 · 进行中 |
| parse_failed | 读取 · 失败 |
| awaiting_confirm | 遮住 · 等你 |
| 轮次 blocked | 复检 · 被拦截 |
| 轮次 queued、running | 模型 · 进行中 |
| 轮次 completed | 还原 · 已过（全线完成） |
| 轮次 partial | 还原已过，模型站带琥珀光圈，写“部分完成” |
| 轮次 failed | 模型 · 失败 |
| completed_local | 本机三站全部已过 |

  已选轮次的状态优先。复检拦截的位置加载完成后才显示“去处理”。会议工具条按最后一次纪要请求显示复检拦截、生成失败或已停止。其他模块同样通过 `utils/trip.ts` 映射。列表接口缺字段时按 V36Q-03 补充。

## 十八、本机与模型地带

* 本机产出放在青色地带：浅青底、锁或计算器图标。包括原文、本机计算、遮住胶囊、本机检查结论、逐字稿。
* 模型产出放在紫色地带：浅紫底、星点图标。包括 AI 建议、模型补查、纪要草稿、云端译文、对话回答。
* 地带是区块级的底色，不是一行标题。现有的 ZoneHeader 扩展为 `SiZone`（标题加区块底）。
