## 一、为什么改

V3.5 的澄明解决了“灰、字小、层次乱”，但各页还是套着同几个模板：

1. **模板化**：文件审核、会议纪要、翻译三个入口都是“虚线框加最近列表”，只换了图标颜色，模块没有自己的样子。
2. **空而无中心**：窄内容列放在大画布上，留白多却没有视觉重心。
3. **数字写成句子**：状态、进度、用量多是一行灰字或小胶囊，没有画出来。
4. **机制看不见**：产品最独特的地方只写在登录页的一句话里，界面上只剩青色按钮。这个地方就是原件不出本机、名称遮住后才给模型、结果回来在本机还原。
5. **Element 默认件露底**：el-tag 16 个文件，el-alert 47 个文件，还有上标签表单，页面像后台模板。
6. **同一件事多套画法**：步骤条、状态徽标、进度条各页各写，彼此不像一家人。

## 二、核心概念：一条衡线，往返一次

标志「衡线」是纸框中部一道伸出纸边的青线，加上右上角的紫色星点。二版把这道线延长成全站的进度语言：一件工作从本机出发，遮住后经网关到模型，再回到本机还原。界面上处处画的是这一趟往返。

**五站**

| 站 | 在哪里 | 颜色 | 一句话 |
|-|-|-|-|
| 读取 | 本机 | 青 | 解析原件，原件不出内网 |
| 遮住 | 本机 | 青 | 名称、金额换成代号，等你确认 |
| 发送前复检 | 本机 | 青 | 出网前再查一遍 |
| 模型 | 云端 | 紫 | 只见遮住后的文字 |
| 还原 | 本机 | 青 | 回到本机换回真实名称 |

* 线段颜色跟着内容走：读取到复检为青，复检到模型为紫，回到还原时变回青。看颜色就知道这段内容出没出过网关。
* **只在本机的工作只有三站**：读取、本机处理、完成，整条青色。包括外发策略为只在本机处理的任务、本地翻译、只做本机检查的标书、发票管家（V36-I）。这条线本身就在说“没有出去过”。
* **可选的模型步骤**：例如标书的模型补查，未发起时不画紫段；发起后再接上紫段。

**站的状态**：颜色说在哪里，光圈说怎么样。

| 状态 | 画法 |
|-|-|
| 未到 | 占位色空心点，细线 |
| 已过 | 站色实心点，实线 |
| 进行中 | 站色实心点，加呼吸光圈；工具条尺度上有光点沿线前进 |
| 等你 | 琥珀光圈，旁边紧跟一个动作按钮，例如“去确认”“去校对” |
| 被拦截 | 复检站换成琥珀实心，旁边写“发送前复检拦截 n 处” |
| 失败 | 红色实心加叉，旁边写原因与重试 |
| 已停止 | 中性实心点，写“已停止” |

天蓝不再表示进行中，只用于“低”等级与说明。这一点改的是 frontend.md 第十二节。

**三种尺度，一套组件 `SiTrip`**

| 尺度 | 用在 | 样子 |
|-|-|-|
| 迷你 | 侧栏近期会话、全局搜索结果、历史记录行、工作台待办、文件标签 | 五个 8px 点，用 2px 短线相连，总宽约 80px；旁边一句当前站的话 |
| 工具条 | 所有工作区顶部 | 站名横排，当前站加粗并带计时；完成后收成一个徽标“已完成 · 用时 1 分 12 秒” |
| 地图 | 设置 · 模型（8.9）、工作台说明浮层 | 本机地带 → 网关四关 → 各模型节点，见 6.20。由 `ExitMap`（components/settings/）画，SiTrip 只做迷你与工具条两种（F-02） |

* **无障碍**：迷你尺度用 `role="img"`，`aria-label` 写全，例如“第 2 站 遮住：等你确认”。工具条尺度用 `<ol>`，当前站带 `aria-current="step"`。状态不只靠颜色，光圈、叉号和旁边的文字同时表达。
* **站名按模块换**：

| 模块 | 工具条站名 |
|-|-|
| 文件审核 | 读取 · 确认遮住 · 复检 · 模型审核 · 还原 |
| 对话 | 读取附件 · 遮住 · 复检 · 模型回答 · 还原 |
| 标书初审 | 读取材料 · 识别扫描页 · 本机检查 · 完成；发起补查后接：遮住 · 复检 · 模型补查 · 还原 |
| 会议纪要 | 本机转写 · 校对 · 确认遮住 · 复检 · 生成纪要 · 还原 |
| 翻译（本机） | 读取 · 本机翻译 · 完成 |
| 翻译（云端） | 读取 · 确认遮住 · 复检 · 模型翻译 · 还原 |
| 发票管家（V36-I） | 读取 · 识别核对 · 校对 · 入台账 |

  迷你尺度一律压成通用五站（或本机三站），具体站名放在 `aria-label` 和悬停提示里。几站压进同一个通用站时，当前站的状态说了算（F-00）：

| 模块 | 压缩方式 |
|-|-|
| 会议纪要 | 本机转写、校对 → 读取；其余四站一一对应 |
| 标书（本机） | 读取材料 → 读取；识别扫描页、本机检查 → 本机处理；完成 → 完成 |
| 标书（发起补查后） | 读取材料、识别扫描页、本机检查 → 读取；遮住、复检、模型补查、还原一一对应 |
| 翻译（本机） | 三站一一对应 |
| 发票管家（V36-I） | 读取 → 读取；识别核对、校对 → 本机处理（有待校对时为“等你”）；入台账 → 完成 |

* **线段颜色**（F-00）：两站都在本机为青；有一端是模型为紫；从模型回到还原的一段前半紫、后半青。只画走过的线段，没走到的用细线占位色。
* **完成徽标**（F-00）：工具条尺度完成后收成“迷你线 + 已完成 · 用时 n”；只在本机的任务在徽标后加“全程本机”。
* **动作按钮**（F-00）：“等你”“被拦截”“失败”三种状态，工具条尺度在当前站名后紧跟一句状态和一个按钮，按钮之后才是未到的站；迷你尺度不带按钮，按钮放在所在行的行尾。

* **状态映射**：状态到站点的对应只写在 `utils/trip.ts` 一处，各页不得自己判断。以文件审核为例：

| 任务 / 轮次状态 | 当前站 |
|-|-|
| draft、parsing | 读取 · 进行中 |
| parse_failed | 读取 · 失败 |
| awaiting_confirm | 遮住 · 等你 |
| 轮次 blocked | 复检 · 被拦截 |
| 轮次 queued、running | 模型 · 进行中 |
| 轮次 completed | 还原 · 已过（全线完成） |
| 轮次 partial | 还原已过，模型站带琥珀光圈，写“部分完成” |
| 轮次 failed | 模型 · 失败 |
| completed_local | 本机三站全部已过 |

  其他模块的映射由 V36-F-01 按同一原则补齐。缺字段时，只在列表接口上补字段，不加表（V36Q-03）。

## 三、全站六条规则

1. **往返线是唯一的进度语言。** 旧的 StepBar、ReviewSteps、状态徽标里的进度、各页自画的进度条，全部换成 SiTrip。真实的数量进度（第 23 / 76 页、62%）作为当前站旁边的文字，不另画一条进度条。
2. **两个地带。**
   * 本机产出放在青色地带：浅青底、锁或计算器图标。包括原文、本机计算、遮住胶囊、本机检查结论、逐字稿。
   * 模型产出放在紫色地带：浅紫底、星点图标。包括 AI 建议、模型补查、纪要草稿、云端译文、对话回答。
   * 地带是区块级的底色，不是一行标题。现有的 ZoneHeader 扩展为 `SiZone`（标题加区块底）。
3. **每个模块有自己的物件。** 审核是一叠纸，合同对比是并排的两张纸，标书是开标桌上的几份标书，纪要是声纹带，翻译是对开的两页，发票管家是夹着一叠票的票夹（V36-I）。入口页从物件开始，不再共用“虚线框加最近列表”。物件插画放在 components/brand/illus/，规格同 frontend.md 第六节：线条、模块色、单个不超过 30 个元素、悬停才动。
4. **每页一张主图。** 主图来自产品机制，见第五节，例如揭幕、地形条、缝线、泳道、出口地图。主图只用现有数据；缺的从现有表聚合，不为它新增统计表；第七节列出每张图的数据来源。
5. **能画的不写成句子。**
   * 计数用迷你柱形或圆环；
   * 进度用往返线；
   * 构成用分段条；
   * 句子只留给原因和下一步该做什么。
6. **默认件全部换皮。** Element 默认件不得原样出现在页面上，替换关系见第四节。

## 四、公共组件

| 组件 | 用途 | 取代 | 要点 |
|-|-|-|-|
| `SiTrip` | 往返线三种尺度 | StepBar、ReviewSteps、进度徽标、el-progress | 第二节 |
| `SiZone` | 本机 / 模型地带 | ZoneHeader 单行标题 | 区块底色、图标、计数、右侧操作槽。操作槽只放一个短按钮或一句说明；筛选分段控件放在地带内第一行，不挤进标题（F-00） |
| `SiBadge` | 胶囊徽标 | el-tag（16 个文件） | 浅底深字全圆，可带图标；语气：中性、青、紫、红、琥珀、天蓝、模块色 |
| `SiNotice` | 就地卡 | el-alert（47 个文件） | 说明（中性）、注意（琥珀）、拦截（琥珀，逐处列出）、错误（红）；写原因加怎么办，可带操作按钮；只有“说明”可关闭 |
| `SiRowCard` | 行卡列表 | 管理列表里的 el-table | 一行一个对象：识别方块、名称加一行辅助、状态徽标、主数据、操作；悬停浮起；可展开详情。名称不断开，名称后的徽标放不下时折到下一行；主数据每块定宽，列与列在行间对齐；行尾操作一个次要按钮加展开箭头，其余操作放进展开详情（F-02） |
| 表格换皮 | 多列、可排序的数据 | el-table 默认外观 | 只在列多于 5 列或需要排序时用；表头 13px 辅助色，行高 56，无竖线，斑马纹不用 |
| 表单 | 设置与抽屉中的表单 | el-form 上标签 | 左标签宽 140、控件宽 360；说明放在控件下方，13px。已按推荐值填好的项显示成只读一行加“修改”，点开才是输入框（F-02） |
| 就地编辑 | 主图或卡片上的单个数值 | 跳转到别的表单 | 点该数值所在的块弹出小卡：一个控件、一句说明、自动保存状态、“完成”；Esc 或再点一次关闭；只放一个设置项（F-02） |
| 逐步检查 | 连接测试、接入新模型一类的多步检查 | 每步一张通过 / 失败提示卡 | 行内一列步骤：未到空心点、进行中转圈、通过打勾、失败红叉加原因；前一步失败，后面的写“未测”，不重复同一个原因（F-02） |
| `SiSpark` | 迷你柱形 | 数字句子 | 按天的计数，周末降透明度；零值画 2px 底线；每根带悬停提示 |
| `SiRing` | 环形用量 | 用量进度条 | 直径 40，线宽 4；超过 85% 变琥珀 |
| `SiStack` | 分段条 | 构成类句子 | 七类脱敏、用途、存储构成；图例在下，点一段可筛选 |
| `SiCount` | 数字滚动 | — | 已有；精简档直接显示终值 |
| `SiStagger` | 依次弹入 | — | 待办、新问题、新行从下方弹入，每项晚 45ms，最多 8 项 |
| 物件插画 | 入口、空状态、404 | 通用空状态图标 | 第三节第 3 条 |
| `EmptyState` | 空状态 | el-empty（2 个文件） | 改用模块物件插画，一句标题、一句说明、一个按钮 |

**取舍说明**

* 动效模式借 Magic UI 的 NumberTicker、AnimatedList、BlurFade，用 Vue 重写，不引依赖。
* BlurFade 只借节奏，不用模糊：基线机器没有显卡，页面进入仍是淡入加上浮 10px（V36Q-05）。
* 跑马灯、地球、流光按钮一类营销效果不用。
* 迁移完成后，页面中不再直接出现 `<el-tag>`、`<el-alert>`、`<el-empty>`；el-table 只留在第四节允许的场合。V36-F-08 走查时用 grep 核对，不为此写测试。

## 五、动效补充（第十一节之外）

| 动效 | 规定 | 精简档 | 关闭档 |
|-|-|-|-|
| 走线 | 工具条和地图上，一个光点沿线前进，过复检后由青变紫，回到还原时变回青。只在状态变化时走一次，不循环 | 不走光点，站点直接切换状态 | 同精简 |

| 揭幕滑块 | 拖动时纸面跟手，无缓动；松手不回弹 | 同完整 | 同完整 |
| 缎带 | 合同对比两稿之间的缎带随滚动重绘，用 requestAnimationFrame 节流，只画可见的部分。新增或删除的一侧没有对应文字时，缎带在那一侧收成一点（F-00） | 滚动时隐去，停止后再重绘 | 不画缎带，只保留两边高亮 |
| 地图点亮 | 模型页首次进入视口时走一遍，节点依次点亮 | 不走 | 不走 |
| 扫票（V36-I） | 第五个品牌时刻。一张发票第一次识别完成时，票列里它的缩略卡上一道青色扫描线自上而下掠过一次（约 0.9 秒），左上角二维码方块随后点亮一次（放大到 1.15 倍再回落）；正在看这张票时，右栏字段依次弹入，金额从 0 滚到终值。再次打开不播放 | 不播放，直接显示结果 | 同精简 |
| 勾稽走线（V36-I） | 勾稽环首次显示时，一个光点沿四条边依次走过，每条约 180 毫秒（边都是直线，光点只用 transform 平移）；不一致的边最后亮起并脉冲一次 | 边直接显示终态 | 同精简 |
| 盖章（V36-I） | 点“核对无误”时，一枚青色圆章“已核对”从 1.4 倍缩到 1 倍并淡入，落在纸面右上角，带 -8° 倾斜，约 300 毫秒；随后纸面向左滑出 24px 淡出，下一张从右侧滑入 | 章直接出现，纸面直接切换 | 同精简 |
| 收进票夹（V36-I） | 一批全部核对完，票列的卡片依次向工具条的“入台账”站收拢（平移、缩到 0.6、淡出，每张晚 45 毫秒，最多 8 张），然后出现完成卡，票夹插画合上 | 直接显示完成卡 | 同精简 |
| 票带生长（V36-I） | 台账主图首次进入视口时，柱子自下而上长出（scaleY，每根晚 30 毫秒） | 静止 | 静止 |
| 释放（V36-I） | 点“完成”后，完成卡票夹里的票依次上浮淡出（每张晚 60 毫秒），夹子合上，一枚锁形图标淡入，写“原件已从内存中清除”，约 0.8 秒 | 直接显示终态 | 同精简 |

性能底线沿用第十一节：只动 transform 与 opacity；SVG 路径重绘不超过每帧一次。完整档在开发机上不低于 55 帧，精简档在 `--disable-gpu` 下不低于 30 帧。

## 六、逐页设计

每页写四项：主图、布局与改法、状态、去掉。没写到的细节沿用 frontend.md 对应小节，功能与交互仍以 SPEC 为准。

### 6.1 外壳：侧栏、账号菜单

* 侧栏结构不变（frontend.md 8.0）。
* 近期会话的模块色圆点换成**迷你往返线的当前站**：只画一个点，颜色和光圈按第二节的规则，悬停显示全部五站。
* 菜单右侧的数字仍只显示等你处理的数量。
* 账号菜单、管理员提醒不变。

### 6.2 全局搜索

* 结果按模块分组，每条带迷你往返线和最近活动时间。
* 键盘上下选择，回车打开；分组标题用模块色识别方块。

### 6.3 登录

## 十、对比度核算与新令牌（F-00）

按 WCAG 2.x 相对亮度公式一次性核算（与 leonardo 的对比度算法等价）。半透明浅底先叠到所在的纸面或卡片上再算；文字要求 ≥ 4.5，图形（圆点、线段）要求 ≥ 3。核算脚本与全部结果见 docs/v36/reports/V36-F-00.md。

**10.1 深色底：全部达标，不改取值。** 灵紫实色 5.46，灵紫深字在浅紫底上 7.31，辅助字在浅紫底、浅青底上 5.11、5.01；七类胶囊字 5.34～7.05；占位点 3.25。

**10.2 浅色底：七类胶囊字不达标，新增深字令牌。** 原来胶囊文字直接用类别色，在各自浅底上只有 2.76～4.16。保持色相、降低明度到 4.6 左右：

| 类别 | 原色（继续用于圆点、描边、分段条） | 在浅底上 | 新增 `--si-k-*-ink`（胶囊文字） | 在浅底上 |
|-|-|-|-|-|
| 单位 org | #2F6BF0 | 4.07 | #1E5FEF | 4.63 |
| 人名 person | #8B4CF0 | 4.16 | #8340EF | 4.63 |
| 联系方式 contact | #0E97B2 | 3.08 | #0B778C | 4.65 |
| 证件 id | #E5711C | 2.76 | #AB5414 | 4.63 |
| 地址 addr | #6E8B1F | 3.50 | #5E761A | 4.60 |
| 金额 amount | #C27A05 | 3.13 | #9A6104 | 4.66 |
| 其他 other | #6B7686 | 4.06 | #636D7C | 4.62 |
