## 一、V312-A-01：四项缺陷修复

按以下顺序执行，每项单独提交。

1. **V312Q-02 + Q-03：共用代号扫描器。**
   * 文件：redaction/restore.py、assistant/stream.py。
   * 让 restore 的候选代号识别同时供 safe_prefix 使用：流式输出时，凡是可能成为候选代号的未闭合前缀（含 `［[`、`【[` 等外层括号变体）都暂扣，保证已发出的还原前缀不再改变。
   * 中性代号的大小写变体（`[[org_1]]`）、全角双括号变体（`［［ORG_1］］`）：在对照表中能唯一对应的，按 variant 还原并标出；不能唯一对应的，标 unknown。不猜真实值。
   * 用例：两个纯函数用例，即审计时的复现输入，外加任意分片的流式拼接结果等于整段还原。
2. **V312Q-04：助手导出带上未还原标记。**
   * 文件：assistant/export.py。
   * 正文与表格在 DOCX 中对标记处加高亮，文末加一句“含 n 处未能还原的代号，请核对”；与审核报告的标记样式一致（复用 export 中已有的标记写法，不新写样式）。
   * 用例：一个，即审计时的复现输入。
3. **V312Q-01：向量辅助按出现位置判断。**
   * 文件：redaction/vector_assist.py、redaction/engine.py（_run 中向量保留的部分）。
   * keep_words 改为对每个待判断项按 loc 和字符区间取上下文；保留结果只作用于该出现位置（以区间记入 vector_kept），不再把词加进全局保留词重新计算。同一词在其他位置仍按其自身上下文判断。
   * 用例：双节点样本写进 golden（同一词在 F1 中是普通词，在 F2 中应替换）。

完成后跑 golden、A-03、回程样本测试与 restore / stream / export / engine 相关测试。报告 docs/v312/reports/V312-A-01.md 不超过一页，末尾写建议的 SPEC 改动（9.9 还原标记、13A 导出、9.3 向量辅助）。
