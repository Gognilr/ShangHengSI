1. **开工条件**：V3-D 已完成（V3-D-04）；本文件与 V3Q-24、V3Q-25 经用户确认；Z-02 开工前测试环境已按 V3Q-24 准备好。

7. **报告**：`docs/v3/reports/V3-Z-test.md`（新），写短；不写密钥、初始密码、根私钥内容，证书只写 SHA-256 指纹。

## 二、候选包与测试环境演练（V3-Z-02，GPT-6.1 Sol，high）

地点按 V3Q-24。下面以“测试虚拟机”指代该环境。

### 2.1 候选包

在仓库外两个干净 clone 中分别构建：标签 `v2.1.0` → `build_release.sh 2.1.0`；main 最新提交 → `build_release.sh 3.0.0-rc1`。各自包内 `sha256sum -c SHA256SUMS` 通过，报告记录两个包的 SHA-256。

### 2.2 安装 2.1.0 并准备虚构数据

1. 按运维说明第 3、5 节全新安装 2.1.0：gen-key、gen-ca（测试根证书，`root.key` 留在测试机以外的目录、演练后删除）、install.sh。
2. 用模拟模型配置单模型（2.1 的设置页或 `cli set-model`）；创建一名普通用户。
3. 普通用户准备：一个 .docx 审核任务走完审核（至少 3 个问题，其中 1 个有建议条文）并追问一次；一个 .doc 审核任务走完审核；一次智能助手对话。

### 2.3 升级到 3.0.0-rc1

按运维说明第 11 节执行 upgrade.sh（虚拟机快照按说明创建；不用 `--skip-backup`）。Caddyfile 有差异时按说明合并。核对：

| # | 检查 | 预期 |
|-|-|-|
| 1 | 五个服务（db、app、worker、converter、web）健康；https 200、未登录接口 401；系统状态版本 | 3.0.0-rc1 |
| 2 | 数据库迁移版本 | 0026 |
| 3 | 设置 → 模型：原单模型已迁为一张卡片，审核默认、助手默认都指向它；“测试连接”成功（说明原密钥迁移后可解密） | 是 |
| 4 | 旧 .docx 任务：结果、旧追问可打开；再追问一次成功；采纳一个有建议条文的问题后导出批注版、修订版 | 成功，Word 能打开 |
| 5 | 旧 .doc 任务：不提供批注版、修订版（V3 之前上传，无转换结果，SPEC 8.8）；重新上传同一 .doc 新建任务后提供 | 是 |
| 6 | 旧助手会话出现在侧栏近期会话，能继续对话 | 是 |
| 7 | 新增第二个模型（模拟服务），新建审核时可选，审核成功 | 是 |

### 2.4 备份、恢复与主密钥更换

1. `backup_now.sh` 手动备份一次；在测试虚拟机的另一目录按运维说明第 10 节用 restore.sh 恢复到新环境（或停掉原环境后原地恢复，二选一，报告写明）。恢复后：普通用户能登录，新上传的 .doc 任务仍能导出批注版（转换结果随原件恢复）。
2. 在恢复后的环境执行一次 rotate_key.sh：之后模型“测试连接”成功（模型密钥已随主密钥更换），.doc 任务仍能导出批注版（转换结果已重新加密）。

### 2.5 员工电脑检查（用户本人操作，共同约定第 6 条）

在一台员工电脑上：

1. 打开 `http://<测试机IP>/cert/` 下载根证书，核对指纹与 `root.sha256` 一致，导入当前用户；Edge 打开 `https://<测试机IP>/` 无警告。
2. Edge“将此站点作为应用安装”，从开始菜单打开，确认独立窗口与图标；截图一张。
3. 工作文件夹：选择一个只含虚构文件的文件夹 → 列表显示文件且**未上传**（网络面板或任务列表无新任务）→ 勾选一个加入审核 → 导出批注版写入该文件夹；同名再导出一次，确认生成带序号的新文件、原文件未被覆盖。
4. 结束后由用户删除测试根证书、卸载应用。

### 2.6 运维说明与收尾

1. 修改 `docs/ops/运维说明.md`：标题改为“商衡SI 运维说明”（不带版本号）；第 11 节改写为通用升级步骤（删去“V2.0.0 全新安装、upgrade.sh 本次不改”与 1.0.1 示例版本号，改用 `<版本>`），并加一段“从 2.x 升级到 3.0”：原模型设置自动迁为一个模型、默认用于审核与助手；V3 之前上传的 DOC、WPS、RTF 须重新上传才能导出批注版 / 修订版。演练中发现步骤与说明不符的，按实际改说明。
2. 删除测试虚拟机上的演练环境（经用户同意）；测试根私钥、测试主密钥删除。
3. 写 V3-Z-test.md 的 Z-02 部分；更新 TASKS-V3 进度后停下，交 V3-Z-03。

**文件范围**：`docs/ops/运维说明.md`、`docs/v3/reports/V3-Z-test.md`；脚本问题按共同约定第 2 条修复（`deploy/scripts/` 下对应文件）。
