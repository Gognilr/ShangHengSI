# V321-E-02 讨论侧栏与讨论稿反馈 完成报告

方案见 docs/v321/design/E-02.md，用户 2026-11-14 确认按推荐实现（A 替换右栏、B、C）。

## 做了什么

* **讨论在结果页右栏**：点“继续讨论”不再切到“直接提问”。讨论替换右侧问题栏，原文画布不动并定位该问题；右栏顶部是该问题卡（默认收起，点开看全文），下面是该问题的对话与输入框，“← 返回问题列表”回到问题栏。问题栏只隐藏不卸载，滚动、选中、筛选原样保留。讨论中点原文上另一处标注，右栏切到该问题；换轮次后问题不在本轮时退出讨论。
* **视图不再重建**：审核视图第一次打开后只隐藏不卸载，“直接提问 / 全面审核”来回切换不丢结果页状态。“直接提问”只显示普通对话，去掉锚点条。
* **讨论稿反馈**：保存后该回复显示“✓ 已保存为问题 n 的修改建议 · 重新保存”（按问题的 `discussed_message_id` 判断，后端输出补该字段，无迁移）；问题卡标题行加“讨论稿”标签，选用时为主色；保存接口返回的问题直接更新结果页，保存后即显示选用讨论稿；对话框加主按钮“保存并采纳”（保存后设为已采纳，第二步失败提示“已保存，采纳未成功”），原按钮改为“只保存”；不再弹全局“已保存”。
* 消息与轮询仍只在 Assistant.vue 一处，讨论区经插槽 ReviewPane → RunResult 放进右栏。发给模型的内容不变。

## 实现与方案的差异

* 右栏顶部直接复用 FindingCard（收起 / 展开），没有另做精简版：展开后内容与问题栏一致，且限制最高 45%，自身滚动。
* SPEC 尚未记录 V3.2 工作台的讨论（按批次惯例在 V321-Z 合并），本任务不改 SPEC。
