# V321-E-06 上传到审核一步确认、解析阶段 完成报告（V321Q-32）

方案 docs/v321/design/E-06.md，用户 2026-11-14 按四项推荐（A～D）确认。

## 做了什么

* **解析阶段**：审核视图解析中只显示 `ParsePhase`——每个文件一行（等待 / 转换旧格式 / 读取正文 / OCR 第 x / N 页 / 完成），最后一行“识别敏感信息与本地校验”；只有 OCR 画确定进度条；解析失败显示原因并可移除文件。后端 `jobs.progress`（迁移 0043）由 `parsing/progress.py` 用独立短会话上报（同一文件同阶段每秒最多一次，失败只丢进度），`SessionDetail.parse_progress` 读取，前端沿用 3 秒轮询。`pdf.parse_pdf` 增加每页 OCR 回调。
* **确认页内嵌**：有待确认文件时审核视图直接内嵌 `ConfirmWorkbench`（新模式 `session-review`），不再弹全屏。右栏底部放立场（按我方买 / 卖方标签带出）、来源、模型、补充说明、查看审核要求；回执显示审核外发正文预览（含主体说明）；文件一节可勾选参与本轮与设主文件；唯一主按钮“确认并开始审核”，键盘快捷键打开。
* **一次调用**：`POST /assistant/sessions/{id}/runs` 加 `confirm_pending`，同一事务里先 `confirm_files`（由原 `confirm` 拆出，不提交）再发起；材料版本过期整体回滚。`GET .../outbound` 加 `include_pending`，确认前即可预览。
* **第二轮**：结果页里新加文件会自动进入新一轮，同样走解析 → 确认页；无待确认文件时仍是设置页，去掉“请先确认脱敏”等提示块。
* 审核视图加文件后不再弹全屏确认（`FilePanel` 的 guided 仅在直接提问视图生效）。
