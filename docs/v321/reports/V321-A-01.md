# V321-A-01 “许可证”规则修复（V321Q-01）

2026-11-13 · 只改 backend/app/redaction/detect.py。

## 改了什么

* `_LICENSE_VALUE` 的截止符补上半角逗号与顿号。识别副本会把全角逗号折成半角，原来只排除全角逗号，“许可证，并在……”逗号后的整句被当成编号。
* 取值分两种：
  * **明确写法**（有冒号，或标签以“编号 / 号码 / 号”结尾，或英文 License / Permit / Certificate No.）：照旧，逐位中文数字也算数字（“粤WH安许证字[二零二四]零零三二一”仍替换）。
  * **标签后直接接文字**：值里必须有原文的阿拉伯数字，且不含“的、应、须、并、且、后、内、至、于……”等叙述虚词。“三日内”“第三方”不再算数字，“排污许可证有效期不少于3年”不再算编号。
* 出口复检与建议条文的字面值闸门用同一函数，随之修正。

## 结果

| 文字 | 改前 | 改后 |
|-|-|-|
| 乙方应取得安全生产许可证，并在合同签订后三日内提供复印件。 | 逗号后整句 → `[证件号]` | 保留 |
| ……和许可证，乙方保证其使用不侵犯第三方权利…… | 标“未能还原”，讨论被拦截 | 不标、不拦 |
| 乙方的排污许可证有效期不少于3年。 | “有效期不少于3年” → `[证件号]` | 保留 |
| 危险化学品经营许可证：苏(宁)危化经字[2023]00123 | 替换 | 替换 |
| 危险化学品经营许可证苏(宁)危化经字[2023]00123（无冒号） | 替换 | 替换 |
