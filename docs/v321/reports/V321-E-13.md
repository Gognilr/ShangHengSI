# V321-E-13 回复依据可定位（Opus）

完成（2026-11-14）。引用结构与锚点写法已于 2026-11-14 经用户确认后实现。

**做法（Q-58）**
* 写回复时，`extras.refs` 只登记本地 id：知识库 `KB n → chunk_id`，历史合同 `H n → task_id、file_seq、locs、“合同，年-月”`。编号与外发包中已有的 `[KB n]`、`[H n]` 一一对应。原来的 `history_sources` 由它取代。
* `message_out` 对已完成的普通问答与讨论回复返回 `sources` 和 `cites`（新模块 `assistant/sources.py`）：
  * 原文段落：取模型输出中、且在本会话里存在的 loc。
  * `[KB n]`、`[H n]`：只认本条回复登记过的编号。
  * 法条：只认该问题 `law_refs` 中、书名与条号都对得上的（中文数字和阿拉伯数字都认，“中华人民共和国”可省）。
  * 对不上的编号，如 `[KB7]`，按原文显示。
* 新接口 `GET …/messages/{mid}/sources/{ref}`：先校验 owner，只放行该回复登记过的 ref。历史合同须仍是本人的、原件仍在；链接按会话或审核分别走 `/assistant` 或 `/review`，修掉了原来一律写 `/review` 的错链接。
* 普通问答也像讨论一样，把模型写出的 `[F1-P12]` 在本机换成可读位置，原来会被标为“未能还原”。列表接口在同一请求内只算一次可读位置（`db.info` 缓存，按 material_version 区分）。
* 提示词：`assistant.md` 加第 8 条（引用写 `[F1-P12]`、`[KB1]`、`[H1]`），讨论说明由“不写位置编号”改为“写段落编号”。提示词版本号升为 `assistant-2026.11-9`。只改说明文字，不新增外发数据，出口复检不变。
* 前端：
  * 新组件 InlineText 负责行内的粗体、未能还原标记和锚点。原文与法条显示为主色虚线链接，`[KB n]`、`[H n]` 换成上标小标签。
  * 回复下新增“依据”行：引用过的在前；附带发送但未引用的排在后面，用虚线次要色。原来的“附带知识库片段 N 段”只保留“N 段未发送”的提示。
  * 点原文：直接提问时打开 FilePanel 新增的“查看原文”层（只读画布），讨论栏里在左侧原文画布上，都会定位并闪烁高亮。点其余依据：打开 FilePanel 的“依据”抽屉，显示本机原文。
