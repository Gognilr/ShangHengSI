## 〇、先回答两个例子

**1. 设置页右侧顶部的标题：不保留。**

* 左侧导航已高亮“个人”，右侧再写一遍 22px 的“个人”是重复；而且两处名称还不一致（导航“账号 / 模型 / 数据 / 脱敏”，标题“账号管理 / 模型接口 / 数据与系统 / 脱敏规则”）。
* 标题下的说明多数与分节说明重复（`Users.vue:191` 与 `:192` 两行都写“新账号首次登录时须先修改密码”；个人页标题说明与外观区末尾的提示重复）。
* 改法：十个设置页去掉 `PageHeader`。原来放在标题右侧的主按钮（如“新增账号”）移到第一个分节标题行的右端；确有必要的整页说明并入第一个分节的说明。`PageHeader.vue` 删除。

**2. 左右两栏对齐：合成一张卡，而不是把两张卡拉齐。**

* 现状有三处错位：① 左卡 `position: sticky; top: 32px`，而页面上内边距是 24px，所以左卡一开始就比右侧低 8px（`SettingsLayout.vue:57`，注释里的“顶栏 64px”早已不存在）；② 右卡被标题再顶下去约 80px；③ 两张卡各按内容定高，底边永远对不齐。
* 两张卡强行等高是假对齐：内容短时右卡下面一大片空白，内容长时左卡被拉成长条。
* 改法（推荐 A）：**设置区是一张占满主区域高度的卡**，卡内左列是导航（220px，右侧 1px 分隔线），右列是内容，只有右列滚动。上下左右四条边由同一张卡决定，任何内容长度都对齐。这也是 macOS 系统设置、Linear 等的做法。分节导航（≥ 4 节时）粘在右列顶部，顺带修掉它现在“白条浮在灰底上”的问题（`SettingsLayout.vue:64`）。
* 备选 B：保持两张卡，只修顶边（去标题、sticky 改 24px），底边不对齐。改动小，但观感提升有限。
