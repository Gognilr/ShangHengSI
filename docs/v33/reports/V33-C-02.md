# V33-C-02 采纳 / 忽略后收起并展开下一条（Opus）

完成（2026-11-15）。用户反馈点了采纳 / 忽略后还要再点一次才收起。

* **做法：** FindingCard 在“采纳”“忽略”保存成功后发 `handled`；FindingsRail 收到后等分段控件滑到新位置（`motionMs('struct')`，特效关闭时不等），展开下一条待处理（从本条往后找，到底再从头找，与快捷键 A / I 相同），没有待处理时再选一次本条即收起。“改回待处理”和保存失败都不动。讨论栏里的问题卡不接这个事件，不受影响。
* **验证：** `npm run build` 通过。浏览器（本机 E02 测试会话，27 条）：第 2 条点“采纳”→ 第 2 条收起、第 3 条展开；第 3 条点“忽略”→ 第 4 条展开；展开第 3 条点“改回待处理”→ 保持展开。走查改动的状态已改回待处理。
* **建议的 SPEC 改动（交 V33-Z）：** 6.8 问题卡处理：点“采纳”“忽略”后自动展开下一条待处理，与快捷键一致。
