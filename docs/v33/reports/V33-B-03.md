# V33-B-03 统一的“页面不存在”页（Opus）

完成（2026-11-15）。用户当天按参考稿《商衡SI 404页面内容整理》确认扩展版：在计划方案（只管未知地址）之上，整页内容打不开也用同一页面。

* **做法：** 新增 `views/NotFound.vue`，两种：`route`（未知地址，标题“这一页已被脱敏”）、`content`（审核结果、旧审核任务、工作台会话、会议、翻译的整页加载返回 404，标题“这项内容无法打开”，文案合并“不存在、已删除或无权限”，不区分他人）。画面是一页被脱敏的文档：文字线、两条黑条、一处 `[机构_1]` 代号，中间 4▮4（“0”为黑条 `[页面_1]`），右上角“查无此页”印章；进入时黑条依次落下（共约 520ms，只播一次，特效关闭直接终态）。下方显示访问的路径（不含查询参数）、按首页显示“回到工作台 / 会议纪要 / 翻译”、“查看历史记录”。浏览器标签为“页面不存在 · 商衡SI”。
* **其他改动：** 路由兜底由跳首页改为该页（在主框架内，未登录仍先去登录页）；`homeFor` 移到 `utils/permissions.ts`；theme.css 新增 `--si-redact-bar`（浅色 #1D1D1F，夜幕 #090B10，避免夜幕下变成白条）。导出、删除失败的提示与局部小资源的 404 不变。
* **验证：** `npm run build` 通过，`test_frontend_style.py` 通过。浏览器 1366×640：浅色 + 完整特效、夜幕 + 关闭特效各看了两种文案，控制台只有未登录的 401。本机没有可用账号（新建测试管理员未获权限），用临时公开路由看的组件，未在登录状态下走 `/abc` 与随机 id 的会话，留 V33-Z 在服务器上补走一遍。
* **建议的 SPEC / frontend.md 改动（交 V33-Z）：** SPEC 前端路由一节写明未知地址与整页 404 显示“页面不存在”；frontend.md 第四节组件表加 NotFound，3.1 注明 404 大字与 SiLogo 同属品牌图形。
