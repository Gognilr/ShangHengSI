# V33-C-01 未选必选项的提示与定位（Opus）

完成（2026-11-15）。用户在确认页找“业务立场”费时，当天提出并确认方案，插在 A-02 之前做。

* **做法：**
  * 新增 `utils/nudge.ts` 的 `nudgeField(el)`：滚到该项（特效关闭时不平滑滚动）、聚焦其中第一个可操作控件、加 `.si-nudge` 闪两下主色框（只动 opacity；特效关闭时显示约 1 秒的静态框）。
  * motion.css 加 `.si-required-empty`（主色虚线框）、`.si-required-tag`（标签旁“请选择”）。
  * ConfirmWorkbench：新增 `blockerChoice` 属性和 `nudge` 事件。缺我方或父页面的选择项时按钮可点，点击定位；`canConfirm` 与 `confirmSend` 的拦截不变。签约方列表在缺我方时标出；条件清单的“请先选择哪一方是我方”和父页面的选择类条件改为可点。
  * ReviewPane：确认页与设置页的未满足条件改为“文字 + 缺项”，按钮只在等待类条件时禁用；立场、模型、我方（设置页）、文件列（设置页）标出并可定位。
* **验证：** `npm run build` 通过。浏览器（localhost:5173，1366×640）用虚构的甲乙方 RTF 合同建会话：确认页显示“请选择我方”“请选择”与虚线框，按钮可点；点一次定位到签约方并聚焦单选框，选我方后再点，定位到业务立场并聚焦第一项，主色框可见（本窗格特效自动为“关闭”，看到的是静态框）。走查会话已删除。
* **未覆盖：** 已确认文件后的设置页（全面审核第二轮起）未在浏览器里点过，写法与确认页相同；完整特效下的闪动只核对了样式，没有目测。
