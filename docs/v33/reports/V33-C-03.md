## 原因与改动

| 现象 | 原因 | 改动 |
|-|-|-|
| “施工”当人名（确定替换 8 处） | “姓 + 称谓”规则把“施 + 工”当作“王工”，在“及施工图纸”处命中后全文传播 | detect.find_persons：姓字与后文连成普通词（plain.surname_in_word，用普通词库切分）时不算称呼；“王工”“方经理”不受影响 |
| “IP55，PLC”当签约方 | PLC 在英文企业后缀表中，识别副本把全角逗号折成半角后与 IP55 连成名称 | parties：PLC 只认“英文单词 + 一个空格 + PLC”（Barclays PLC） |
| DCS、PTO、PLC 待判断 | 实体识别中置信，缩写不在 plain_terms | plain_terms.txt 增工控、电气、仪表通用缩写与 Pt100、IP55 等 37 条 |
| 汽阀总成 待判断 | 实体识别中置信，“汽、阀”不在普通词库 | 实体识别中置信结果为“2～6 字 + 总成 / 装置 / 系统 / 阀 / 控制器 / 传感器 / 热电阻……”且无名称证据时自动保留，原因“设备或部件名称”（suspects.ordinary_reason；前端 AUTO_KEPT_REASON 加一条） |
| 型号只切出 WZP | 实体识别把连字符型号切开 | 实体识别中置信结果落在字母数字型号中间时扩到整个型号，空格后紧跟的含数字规格段并入（suspects.model_token），仍为待判断 TERM |

“土建”是连带修复：“施工”不再被替换后，实体识别不再在“土建”处给出名称。
