# V3.3 问题记录

编号 V33Q-01 起；V3.2.1 及以前的问题见 docs/v321/open_questions.md 等各阶段文件。新问题接着往下编号，写现象、做法与状态，每条几行。

### V33Q-01 构建脚本要求 `python3`，Windows 构建机上是应用商店占位程序（低，V33-A-01）

* 现象：V321-Z 构建发布包时，本机 `python3` 是占位程序，要临时定义 shell 函数指到 `python` 才能构建（docs/acceptance/V3.2.1升级记录.md）。
* 做法：依次试 python3、python、py -3，以能真正执行为准；可用 `PYTHON` 指定。见 PLAN A-01。

### V33Q-02 升级包每次带全部镜像（中，V33-A-02）

* 现象：3.2.1 包 9.4 GB，转写、翻译等模型镜像多数版本不变，也随包传输、导入。
* 做法：`--base` 指定上一版包，按各镜像构建目录的 git 差异决定重建或沿用；upgrade.sh 按镜像 ID 核对服务器已有镜像并打新标签，缺失则在备份前停止；install.sh 拒绝增量包。见 PLAN A-02。

### V33Q-03 会议纪要旧数据兼容未验证（中，V33-B-01）

* 现象：V321-Z 无录音样本，只验证了旧审核、旧会话、旧翻译（V321-Z 遗留第 1 条）。
* 做法：本机合成虚构录音，在 v3.1.0 上造旧会议，换 main 后逐项打开。见 PLAN B-01。

### V33Q-04 真实模型是否按提示词写依据编号（中，V33-B-02）

* 现象：E-13 的锚点只用模拟回复验证过（V321-Z 遗留第 2 条）。
* 做法：约 12～16 次真实调用、虚构样本，统计可定位比例、变体写法与错指；必要时放宽本地识别或改提示词说明。见 PLAN B-02。

### V33Q-05 是否加统一的“页面不存在”页（用户 2026-11-15 确认做，承接 V321Q-67）

* 现状：未知路径直接回首页、不提示；任务 / 会话不存在时各页就地提示（不区分他人与不存在）。
* 建议：只为未知路径加一个主框架内的“页面不存在”页，各页就地提示不变。方案见 PLAN B-03，用户 2026-11-15 随计划确认。
