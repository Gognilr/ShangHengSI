# V32-B-02 报告：按问题讨论

完成：2026-11-12（Sonnet）。

* **入口与锚点：** 问题卡加“继续讨论”（审核进行中、原件已删除、轮次未完成时不显示）。点击后工作台切到提问视图，顶部显示锚点卡（问题序号与标题、所属轮次、“回到审核结果”“解除”）；锚点只存在于当前页面，换会话即清除。有锚点时只显示该问题下的对话，普通对话与各问题互不混入。只有 use.review 的用户在有锚点时可以提问（用默认助手模型）。
* **接口：** `MessageIn` 加 `finding_id`；预览、发送、重试都先校验该问题属于本会话（否则 404 FINDING_NOT_FOUND）；带锚点的消息不允许同时用模板，权限按 use.review。用户消息与回复都写入 `assistant_messages.finding_id`（A-01 已建列），消息输出带 `finding_id`。
* **上下文（新 assistant/context.py）：** 问题结论（标题、类别、等级、位置、问题、影响、审核建议、建议条文、依据，代号文本）+ `locs` 对应节点及前后各 2 段 + 同一条款号的节点（每处最多 12 段，最多取 5 处位置）+ 该问题下最近 10 条已完成消息。不带整份文件、本地校验摘要，也不带普通对话；`build_messages` 的普通历史排除了所有带锚点的消息。
* **长度：** 以模型的 `chunk_chars` 为预算。问题与条款加提问放不下 → 409 CONTEXT_TOO_LONG（发送前、重试前就拦，不进队列、不截条款）；只是历史太长时丢最早的几条。
* **提示词：** 系统提示追加一句讨论说明（只对照该问题的原文回答，改写时给完整替换条文并说明理由）；`VERSION` 改为 assistant-2026.11-7，新增固定文字并入 `fixed_prompt_text`（出口复检的固定文本）。日期平移说明沿用。
* **保留期：** 原件层到期后，发送仍走 `_writable`，返回 SESSION_READONLY；“不再选用”的文件（未删）照常可讨论。

测试：新增 test_finding_discussion.py 一例（文末条款的问题上下文含该条款且不含开头条款；问题 A、B 与普通对话的历史互不混入；跨会话与不存在的 finding_id 返回 404；CONTEXT_TOO_LONG）；助手、会话、会话审核、工作台读取共 81 项通过。`test_assistant_chat.py` 的版本号断言随 VERSION 改为 -7。前端 `npm run build` 通过。未在浏览器里走界面（需起整套系统）。
